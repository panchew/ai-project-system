## The five delegated design decisions — decided, documented, proceeded

1. **Reference artifact location:** a **new** directory,
   `.ai-project/artifacts/reference/opencode-model-declarations/`. None of the five existing
   siblings covers host engine configuration, and filing it under `token-measurement` or
   `local-paid-comparison` would have buried a record of a **host mutation** inside a measurement
   series.
2. **Limit derivation:** **Drivr's `observe_loaded_context`** (HEAD `f60164c`), not a direct
   `/api/ps` read. The adapter rewrites this value on every dispatch from its own observation;
   deriving it by a second path risks declaring a number the adapter then disagrees with. Reuse
   makes agreement structural. Cost: one cross-repo citation, paid.
3. **Resolution table layout:** two tables — the seven strings, then the evidence per row — so a
   consumer can read strings without wading through provenance, while provenance stays one hop away.
4. **R4 probe model:** **`llama3:8b`** — in Ollama, absent from `opencode.json`, and **not** a model
   this epic declares, keeping the answer independent of this epic's own change. *"It ran"* was
   defined as **exit 0 with model-generated output in the event stream**, the same bar the other
   dispatches met, committed before the run.
5. **Artifact split:** **D1/D2/D5 as one record; D4 and D6 standalone.** D4 must be readable as a
   standalone record of an out-of-repo mutation; D6 must be routable to the parent without carrying
   400 lines of measurement with it.

— a lane running unmanaged all along — is NOT present**, because the engine refuses first.
