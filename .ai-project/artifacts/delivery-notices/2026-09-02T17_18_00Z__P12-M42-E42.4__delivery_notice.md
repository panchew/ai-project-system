# Delivery Notice: P12-M42-E42.4 — `ai-project-init` Stops Manufacturing an Agent

## Summary

**`bin/ai-project-init` no longer manufactures a governance agent. It locates the real one, and
when the evidence is genuinely absent it stops and says so.**

The initializer's `install_hq_agent` read the agent source one `governance/` level short of where a
real submodule clone puts it, wrote a 230-byte "Milestone M8" placeholder in its place, validated
the placeholder's shape (readable / non-empty / starts-with-`#`), and reported success — and
`tests/test_init_agent_path.py` recorded that as correct. `P12-GH-2`, severity High, the one of
M42's four defects not on the orchestrator or the merge script.

**What it does now:** the source path and the `submodule_path` are coupled to one named constant
(`GOVERNANCE_SUBMODULE_PATH=".governance"`, the M38 fleet convention and PSG §14B), the stub branch
is removed, and the validator asserts the agent's identity marker (front-matter `name: hq`) on the
**source, before the copy** — so a placeholder never even lands on the canonical
`.ai-project/agents/` path. The M38 "hard-coded with no flag" finding is disposed of deliberately
(a recorded hard-coded default, not a permissive flag). The test is inverted: the suite fails if a
placeholder is installable, and `P6-GH-11`'s canonical-path coverage survives.

**Obligation 1 — the real end-to-end run — CONFIRMS the inference.** Four real inits, no
`--skip-submodule`, into scratch directories only. The unfixed script produced the 230-byte stub on
both the default `v2.0.0` ref (A1) and `master` (A2) — A2 isolates the off-by-one, since the real
14,711-byte agent existed at the correct depth and was still never found. The fixed script installed
the real agent at the canonical path (B1) and failed closed with a stated reason on the default
`v2.0.0` ref (B2). **Two findings beyond the note, both recorded:** the CWD-drift nesting (the stub
did not even land at the canonical path; fixed, proven by B1) and the stale default ref (`v2.0.0`
predates the canonical agent file; a default init now fails closed, which is the milestone's correct
disposition — the ref is not bumped here and is left to the milestone / E42.5's blast radius).

**Both guards were falsified** — with the validator's identity assertion removed, the M8 placeholder
was accepted; with the no-stub abort removed, the init succeeded with the placeholder on disk.
