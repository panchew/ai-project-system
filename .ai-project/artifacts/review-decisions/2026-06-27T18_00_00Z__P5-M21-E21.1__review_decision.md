## Disposition of the one deviation (accepted)

`bin/ai-project-init` still writes the agent to `.github/agents/`. That CLI file is **outside
E21.1's named file scope** (the Epic edits guides, not the CLI), so the Coding Agent correctly left
it untouched and instead kept the guide depiction of the CLI output **truthful**, annotating it to
point at the neutral canonical path and treating the `.github/agents/` copy as Copilot's
convenience. This does not violate AC2 (no guide makes that path canonical/required). Recorded as a
**follow-up candidate**: a later Epic could teach the CLI to also write `.ai-project/agents/`. Not a
blocker for E21.1 acceptance.
