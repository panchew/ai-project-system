## Finding 1 — paid run 2 violated the frozen session and isolation conditions (blocking)

Paid run 2 metadata states all three facts plainly:

1. its engine was a `claude-code fresh subagent context (operator-dispatched)`;
2. the addendum required a fresh manual session, and the metadata leaves that mismatch for the
   reviewer; and
3. isolation was **instructed, not sandboxed** — the host process retained tool access capable of
   reading beyond the packet.

The post-hoc transcript scan says the arm used only one `Read` call, against the sealed packet. That
supports a useful observation about what the run did. It does not make unavailable the repository
access that remained available, and it does not turn a programmatic subagent into the registered
manual arm. The previous decision explicitly required stopping and escalating if packet-only
isolation could not be provided.

Paid run 2's output may remain as useful evidence, but it is a second protocol-invalid paid trial.
It must not be scored as the paid CATCH in the controlled pair.

### Required rework

Before another paid run, commit a second protocol-correction addendum that:

1. preserves paid run 2 and classifies it INVALID for session-type and unenforced-access mismatch;
2. authorizes exactly one paid run 3 solely as replacement for that invalid trial;
3. keeps the original rubric and prompt frozen; and
4. freezes the execution as a genuinely fresh, human-operated manual chat at
   `models.epic_manual`, with no inherited conversation, no local-repository connector, no shell,
   no filesystem/search tool, no evaluator follow-up, and no context other than the exact sealed
   packet.

Commit the exact sealed input as a new evidence file **before run 3**. The independently recovered
run-2 input above is suitable if retained byte-for-byte; committing it makes the prompt boundary and
absence of the answer verifiable after temporary files disappear. Record its byte count and hash.

Then paste that exact input into one fresh manual session and make no follow-up intervention. Commit
the exact output/transcript, model identity evidence, start/end timestamps, and elapsed wall-clock
time. Score that one output against the unchanged rubric from its proposed artifacts, not from its
summary prose. Preserve all three paid attempts; do not select by quality. If the required manual,
packet-only conditions cannot be provided, escalate instead of substituting another execution mode.

Local run 2 must **not** be rerun. Recompute the comparison using local run 2 and paid run 3,
whatever paid run 3's quality result is.
