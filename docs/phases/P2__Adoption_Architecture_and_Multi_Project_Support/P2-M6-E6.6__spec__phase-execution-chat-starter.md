# Epic E6.6 — Phase Execution Chat Starter

## Context

The AI Project System currently has two chat-layer governance documents:

- **HQ Chat** — the control room; defines phases, milestones, epics
- **Epic Execution Chat Starter** — launches a Coding Agent to execute a single epic

The middle layers are missing. A Phase planning chat needs a starter just as much as an epic execution chat does. Without it, there is no standard way to launch a Phase-scoped planning session, and HQ Chat bears all planning responsibility indefinitely.

This Epic creates the Phase Execution Chat Starter: a governance document and fillable template that launches a Phase Chat responsible for producing Milestone specs and Milestone Execution Chat Starters.

---

## Problem Statement

Without a Phase Execution Chat Starter:

- No standard way to delegate Phase planning from HQ Chat
- Milestone specs are always written in HQ Chat, which accumulates unbounded context
- No defined role or scope for a "Phase Chat"
- The chat hierarchy (HQ → Phase → Milestone → Epic) has two missing rungs

---

## Goals

By the end of this Epic:

1. The role and responsibilities of a Phase Chat are defined in a system document
2. A fillable Phase Execution Chat Starter template exists in `/governance/templates/`
3. Both documents are cross-referenced in `PROJECT-SYSTEM-GUIDELINES.md`

---

## Non-Goals

- Creating the Phase Chat as a VS Code agent (P3)

- Implementing any runtime behavior

## Scope of Work

### 1. Write `phase-execution-chat-starter.md` system doc

Create `/governance/systems/phase-execution-chat-starter.md` defining:

**Role of a Phase Chat:**
- A Phase Chat is a planning session scoped to a single Phase
- It is launched from HQ Chat with the Phase Execution Chat Starter
- It does NOT execute work — it plans and produces artifacts
- It has read access to the Phase spec and all Milestone stubs within the Phase

**Responsibilities:**
- Review the Phase spec and confirm it is complete
- Produce Milestone specs for all milestones in the Phase
- Produce a Milestone Execution Chat Starter for each Milestone
- Hand off Milestone Execution Chat Starters back to HQ Chat (or directly to Milestone Chat)

**What it is NOT:**
- A coding agent
- A place where branches are created or files are modified directly
- A substitute for the HQ Chat's authority

**Governance authority chain:**
1. PROJECT-SYSTEM-GUIDELINES.md
2. AI-OPERATING-GUIDELINES.md
3. Phase Execution Chat Starter (this document type)
4. Phase Spec
5. Decisions made during the session

### 2. Write the Phase Execution Chat Starter template

Create `/governance/templates/phase-execution-chat-starter.md` — a fillable template with placeholders, modeled on the existing Epic Execution Chat Starter template:

**Required fields:**
- Project name and repository
- Phase number and name
- Phase spec path
- Governance document versions
- Current milestone stubs (list)
- Session objective (what this Phase Chat must produce)

**Sections:**
- Governance References
- Phase Context
- Spec Existence Requirement
- Output Requirements (Milestone specs + Milestone Execution Chat Starters)
- Execution Instructions
- Completion Requirements
- Question Policy

### 3. Update `PROJECT-SYSTEM-GUIDELINES.md`

Add a reference to the Phase Execution Chat Starter in the section covering chat roles and planning hierarchy.
