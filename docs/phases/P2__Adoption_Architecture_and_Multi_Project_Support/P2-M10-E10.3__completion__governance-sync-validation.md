## Key Findings

1. **Sync workflow validated** — Commands in `submodule-setup.md` §6 work correctly end-to-end
2. **Rollback is simple** — Same procedure as update, just targeting an older tag
3. **Modern git handles submodule pointer conflicts** — Git 2.43+ auto-resolves SHA conflicts in submodule references; `.gitmodules` conflicts are the only content-level conflicts
4. **`v2.0.0` tag was missing** — Created at current milestone/M10 HEAD
5. **Timing margins are excellent** — Full sync takes < 30s; rollback takes < 20s (vs. 10 min / 5 min acceptance criteria)

---

## Deviation from Plan

- **Scenario 4 (Merge Conflict):** The original test plan described submodule *pointer* conflicts. Testing revealed that modern git auto-resolves these. The scenario was adapted to test `.gitmodules` content conflicts, which produce real merge conflicts. The test plan and sync guide note this distinction.
