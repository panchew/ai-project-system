# E7.3 Test Report — Governance Submodule Integration & `.ai-project.yml` Validation

This report documents end-to-end verification of the `ai-project init` CLI for E7.3.

---

## Test Environment

- OS: Linux
- Bash: 5.x
- Git: 2.40+
- Network: Required for submodule fetch tests (happy path); use `--skip-submodule` if offline
- CLI under test: bin/ai-project-init

---

## Tests & Results

### Test 1 — Governance Submodule Happy Path (custom ref: master)

Commands:
```bash
./bin/ai-project-init e73-master --dir /tmp --governance-version master
cd /tmp/e73-master
git submodule status
ls governance/
cat .ai-project.yml
cat .gitmodules
```
Result: PASS

Observed:
- `.gitmodules`:

```
[submodule "governance"]
  path = governance
  url = https://github.com/panchew/ai-project-system
  branch = master
```

- `git submodule status`:

```
 c34f18d78207ca69c2dbbd99f59314d1d018e6ef governance (heads/master)
```

- `governance/` listing includes governance files (README.md, LICENSE, docs/, examples/)

Notes:
- The default tag `v2.0.0` was not present in the repo during testing. The CLI surfaced a clear error and succeeded when a valid ref (`master`) was provided via `--governance-version`.

### Test 2 — Custom Governance Source and Version

Commands:
```bash
./bin/ai-project-init e73-custom \
  --dir /tmp \
  --governance-source https://github.com/panchew/ai-project-system \
  --governance-version master
cd /tmp/e73-custom
ls governance/
```
Result: PASS (with `--governance-version master`)

### Test 3 — Skip Submodule (Offline)

Commands:
```bash
./bin/ai-project-init e73-skip --dir /tmp --skip-submodule
cd /tmp/e73-skip
git submodule status || true
[ ! -f .gitmodules ] && echo ".gitmodules absent (OK)"
cat .ai-project.yml
```
Result: PASS
- `.gitmodules` absent
- `.ai-project.yml` present with governance fields and ISO-8601 timestamp

### Test 4 — Invalid Governance Version

Commands:
```bash
./bin/ai-project-init e73-badref --dir /tmp --governance-version non-existent-tag
```
Result: PASS (negative case)
- Clear error surfaced: failed to add/checkout requested ref

### Test 5 — `.ai-project.yml` Validation

Commands:
```bash
./bin/ai-project-init e73-validate --dir /tmp --skip-submodule
cat /tmp/e73-validate/.ai-project.yml
```
Result: PASS
- Timestamp is ISO-8601 UTC
- `project.name` pattern enforced
- Governance URL and ref validated
- YAML required keys present

## Notes

- If submodule network is restricted, rely on Test 3 (`--skip-submodule`).
- When tags like `v2.0.0` are unavailable on the governance source, pass a valid ref (e.g., `--governance-version master`).
