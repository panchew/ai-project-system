# E7.3 Test Report — Governance Submodule Integration & `.ai-project.yml` Validation

This report documents end-to-end verification of the `ai-project init` CLI for E7.3.

---

## Test Environment

- OS: Linux
- Bash: 5.x
- Git: 2.40+
- Network: Required for submodule fetch tests (happy path); use `--skip-submodule` if offline
- CLI under test: bin/ai-project-init

---

## Tests

### Test 1 — Governance Submodule Happy Path

Commands:
```bash
ai-project-init e73-happy --dir /tmp
cd /tmp/e73-happy
git submodule status
ls governance/
cat .ai-project.yml
cat .gitmodules
```
Expectations:
- `governance/` present and populated
- `.gitmodules` contains governance entry with correct URL and branch
- `.ai-project.yml` includes correct source/version and `submodule_path: governance/`

### Test 2 — Custom Governance Source and Version

Commands:
```bash
ai-project-init e73-custom \
  --dir /tmp \
  --governance-source https://github.com/panchew/ai-project-system \
  --governance-version v2.0.0
cd /tmp/e73-custom
ls governance/
```
Expectations:
- Submodule initialized from specified source at specified version

### Test 3 — Skip Submodule (Offline)

Commands:
```bash
ai-project-init e73-skip --dir /tmp --skip-submodule
cd /tmp/e73-skip
git submodule status || true
[ ! -f .gitmodules ] && echo ".gitmodules absent (OK)"
cat .ai-project.yml
```
Expectations:
- No submodule present; `.gitmodules` absent
- `.ai-project.yml` still records governance fields

### Test 4 — Invalid Governance Version

Commands:
```bash
ai-project-init e73-badref --dir /tmp --governance-version non-existent-tag
```
Expectations:
- Fails with error: "Failed to add governance submodule ... at 'non-existent-tag'"

### Test 5 — `.ai-project.yml` Validation

Commands:
```bash
ai-project-init e73-validate --dir /tmp
cat /tmp/e73-validate/.ai-project.yml
```
Expectations:
- Timestamp in ISO-8601 UTC format (YYYY-MM-DDTHH:MM:SSZ)
- `project.name` matches required pattern
- `governance.source` starts with http/https
- `governance.version` matches allowed ref pattern
- YAML structure contains required keys

---

## Notes

- Use `PATH` or full path to invoke: `./bin/ai-project-init` from repo root.
- If submodule network access is restricted, rely on Test 3 (`--skip-submodule`).
- When network is available, rerun Tests 1–2 to confirm `.gitmodules` and submodule contents.
