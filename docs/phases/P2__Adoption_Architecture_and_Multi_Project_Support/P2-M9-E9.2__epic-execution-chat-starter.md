### Summary

Publish a formal Override Boundaries governance document enumerating overridable vs. core dimensions with rationale, and document how override values flow from `.ai-project.yml` through the HQ agent to generated artifacts.

### Problem Statement

Override boundaries are mentioned in the Milestone spec but not formally published. The system integration path — how overrides propagate from config to artifact — is undocumented. The HQ agent (E9.3) has no specification for where override values should be consulted during artifact generation.

### Goals

1. Override Boundaries document published in governance
2. System integration documentation describing the full override flow
3. Governance documents cross-reference the Override Boundaries
4. HQ agent updated with override integration placeholders
