## Key Decisions

1. **Project 2 selection:** Used `panchew/home_finance` (Ruby on Rails) as the external project — a real-world codebase with existing documentation, chosen by human coordinator
2. **Existing project path:** For home_finance (which already has code), used the Legacy Migration Guide Workflow B instead of the main adoption guide's `ai-project init` path
3. **Friction point prioritization:** Identified "CLI not published to npm" and "v2.0.0 git tag missing" as critical blockers for public adoption, documented with workarounds
4. **Guide edits scope:** Focused guide edits on the most impactful changes from friction analysis — prioritized "existing project" callout and "CLI not found" FAQ as high-severity issues
