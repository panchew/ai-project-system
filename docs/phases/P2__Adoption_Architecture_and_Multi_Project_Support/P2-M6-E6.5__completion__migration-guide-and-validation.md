### Issue Found and Resolved

**Issue:** `docs/governance/governance-folder-structure.md` existed in a non-canonical `docs/governance/` subfolder. The canonical `docs/` structure (per `governance/PROJECT-SYSTEM-GUIDELINES.md` Section 3) permits only: `README.md`, `roadmap/`, `phases/`, `decisions/`, `context/`, `_legacy/`, `admin/`.

**Root Cause:** E6.1 created `docs/governance/governance-folder-structure.md` as the epic deliverable. The E6.2 completion report noted it "remains at `docs/governance/governance-folder-structure.md` as a project artifact" — but the canonical location for P2-M6 epic deliverables is `docs/phases/P2__Adoption_Architecture_and_Multi_Project_Support/`.

**Fix:** Moved via `git mv` to `docs/phases/P2__Adoption_Architecture_and_Multi_Project_Support/P2-M6-E6.1__deliverable__governance-folder-structure.md`. The `docs/governance/` directory was removed.
