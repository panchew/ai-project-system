# Version Upgrade Validation Test Plan — P2-M8-E8.4

## Objective
Validate upgrading an existing governed project to a newer governance version and refreshing `.ai-project.yml` as needed.

## Environment
- Platform: Linux (required), macOS/WSL2 (optional)
- Tools: `git`, `bash`

## Preconditions
- Existing project initialized by `ai-project init` at an older governance version (e.g., `master` → `milestone/M8`)

## Procedure (Linux)
1. Create a baseline project at an older version (if needed):
   ```bash
   ./bin/ai-project-init e84-upgrade --dir /tmp --governance-version master
   cd /tmp/e84-upgrade
   ```
2. Update `.ai-project.yml` governance version (example):
   ```bash
   sed -i 's/version: .*/version: milestone/M8/' .ai-project.yml || true
   ```
3. Refresh governance submodule to target version:
   ```bash
   git -C governance fetch --tags --quiet || true
   git -C governance checkout -q milestone/M8
   git add .ai-project.yml governance
   git commit -m "Upgrade governance to v2.0.1" || true
   ```
4. Verify working state:
   ```bash
   git status --porcelain=v1
   test -r .github/agents/hq.agent.md && echo OK:hq.agent.md
   ls -la governance | sed -n '1,60p'
   ```

## Expected Results
- `.ai-project.yml` reflects the new governance `version`
- `governance/` content updated; repository remains in a valid, usable state
- HQ agent remains present and readable
- Git status is clean after commit

## Pass/Fail Criteria
- PASS if upgrade completes and project remains valid/usable
- FAIL if submodule refresh fails or project is left inconsistent
