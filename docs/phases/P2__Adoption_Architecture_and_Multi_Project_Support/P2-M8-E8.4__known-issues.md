# Known Issues & Recommendations — P2-M8-E8.4

## Known Issues
- Network dependency: Governance submodule initialization requires internet; use `--skip-submodule` for offline dry runs.
- Git configuration: Users without global git identity may see commit failures; advise `git config user.name/email` setup.
- VS Code agent selection: Some environments may need manual selection of the `hq` agent after opening the project.

## Recommendations
- Document fallback: When governance agents are unavailable, the CLI stub ensures HQ path remains usable.
- Prefer stable branches like `milestone/M8` or `master` in `.ai-project.yml` for reproducibility.
- Capture test evidence (screenshots or transcripts) for HQ prompt interactions.
