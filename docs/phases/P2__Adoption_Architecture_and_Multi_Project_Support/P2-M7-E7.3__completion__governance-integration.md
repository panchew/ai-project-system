## Summary

The `ai-project init` CLI has been extended to:
- Add governance as a git submodule by default, pinned to a specified version/ref.
- Validate `.ai-project.yml` before writing (project name, timestamp, URL, ref/version, YAML shape).
- Support `--governance-source`, `--governance-version`, and `--skip-submodule` flags.
- Ensure `.gitmodules` is created in the initial commit when submodule is added.

## Implementation Notes

- Submodule path: `governance/` (per E7.3 spec for generated projects)
- Validation:
  - `project.name`: `^[a-z0-9]([a-z0-9-]*[a-z0-9])?$`
  - `created_at`: `YYYY-MM-DDTHH:MM:SSZ` (UTC)
  - `governance.source`: `^https?://`
  - `governance.version`: `^[a-zA-Z0-9._/-]+$`
  - YAML shape: sanity checks for required keys
- Help: `--skip-submodule` description updated to indicate offline/testing use
- Error messages: actionable and specific (invalid URL/ref, submodule add/init failures)
