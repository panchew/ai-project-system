The specification defines the complete interface and behavior for the `ai-project init` CLI command:

### CLI Command Interface
```bash
ai-project init <project-name> [options]

Options:
  --dir <path>                    Directory where project will be created (default: current dir)
  --governance-source <url>       Git URL for governance (default: https://github.com/panchew/ai-project-system)
  --governance-version <tag>      Git tag/branch (default: v2.0.0)
  --skip-git                      Don't initialize git repo
  --skip-submodule                Don't add governance submodule
  --help                          Show help text
  --version                       Show CLI version
```
