### Summary

Create 3+ example `.ai-project.yml` configurations for common project types (library, application, monorepo workspace), validate each against the override spec, and document troubleshooting guidance for common override issues.

No example `.ai-project.yml` files exist for different project types. Project leads have no reference to follow when configuring overrides. There is no validation confirming override configurations pass spec validation, and no troubleshooting guidance for common mistakes.

### Goals

1. 3 example configurations for library, application, and monorepo project types
2. Each example validated against `.ai-project.yml` spec
3. Troubleshooting guide for common override issues

7. `project.description` is non-empty
