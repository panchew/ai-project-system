**Full spec:** `docs/phases/P13__Daily_Fleet_Operation_in_Drivr/P13-M48-E48.3__spec__enrollment-completes-the-delivery-substrate.md`

The Epic spec is the authoritative copy of **Deliverables (D1–D4), Definition of Done, Acceptance
Criteria, Binding Constraints, Non-Goals, and Notes.** **This starter does not duplicate them.**
Cite the spec by path and branch — **not** by a version number or sha.

**The four things easiest to get wrong, flagged here and specified there:**

1. **A config line without verification.** Writing a `remote` into `.git/config` is not enrollment;
   verification (e.g. `git ls-remote` against a local bare repo) is the proof.
2. **Treating local-only as delivery-ready.** Local-only is explicit and recorded, never a silent
   default read as fleet-ready.
3. **Emitting credentials.** The path never reads or prints authentication material.
4. **Letting enrollment change fleet state.** It configures a remote; it never activates, never
   dispatches, never writes fleet registry state.
