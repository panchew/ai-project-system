The Epic spec is the authoritative copy of **Deliverables (D1–D4, D2a), Definition of Done,
Acceptance Criteria, Binding Constraints, Non-Goals, and Notes.** **This starter does not duplicate
them.** Cite the spec by path and branch — **not** by a version number or sha.

**The four things easiest to get wrong, flagged here and specified there:**

1. **Reachability as verification.** `git ls-remote` proving the URL answers is not proof of a
   tracking relationship, a pushed branch, or ref equality; enrollment proves all three.
2. **Local-only as a transient result.** Local-only is a durable, committed disposition, never a
   silent default and never conflated with "remote absent."
3. **Emitting credentials.** The path never reads or prints authentication material.
4. **Letting enrollment change fleet state.** It configures a remote and records a disposition; it
   never activates, never dispatches, never writes fleet registry state.
