The Epic spec is the authoritative copy of **Deliverables (D1–D4), Definition of Done, Acceptance
Criteria, Binding Constraints, Non-Goals, and Notes.** **This starter does not duplicate them.**
Cite the spec by path and branch — **not** by a version number or sha.

**The four things easiest to get wrong, flagged here and specified there:**

1. **Converting the live check into a hidden skip or mock.** Skip must be recorded and reasoned,
   never silent.
2. **Folding live qualification into "suite green."** Report two lines: deterministic totals and
   live qualification.
3. **A mock standing in for the live endpoint.** A deterministic stub is only for plumbing proof,
   labeled, and never substitutes for the real check in a qualification report.
4. **Breaking the unchanged config contract.** `visual_artifacts.enabled` and
   `AI_PROJECT_SKIP_LIVE_ENDPOINT_TESTS` semantics stay as they are.
