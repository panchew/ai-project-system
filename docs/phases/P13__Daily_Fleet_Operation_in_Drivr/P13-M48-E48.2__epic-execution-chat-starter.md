Cite the spec by path and branch — **not** by a version number or sha.

**The four things easiest to get wrong, flagged here and specified there:**

1. **Converting the live check into a hidden skip or mock.** Skip must be recorded and reasoned,
   never silent; a mock never substitutes for the real check.
2. **Folding live qualification into "suite green."** Report two signals via `bin/suite-gate`;
   its exit reflects `deterministic` only, and a live `fail`/`skip`/`deferred`/`config-error` never
   alters the deterministic gate.
3. **Leaving the split descriptive instead of executable.** The two commands and `bin/suite-gate`
   must be real, committed, and tested — not prose.
4. **Mislabeling a pre-call exit as a runtime failure.** Exits 2/3/5 happen before generation; only
   exit 4 is a runtime `fail`. Keep the exit meanings; match the label to them.
