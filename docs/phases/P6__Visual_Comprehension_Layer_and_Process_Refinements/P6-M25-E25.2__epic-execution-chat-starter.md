### Summary

**This is the subtle epic of M25 — a reconciliation, not an append.** Codify **SN-13 default-accept**
(*a parent chat auto-accepts a clean child delivery by silence; a Review Decision is the exception
path only*) into **AOG + PSG + the two Execution Chat Starter templates**, **and reconcile** the
contradictory always-review language — **without deleting the Layer-8 human-review requirement.**
**Documentation only.**

### Problem Statement

SN-13 default-accept has governed every delivery since P5 (all of M23/M24, and E25.1), but the
codified text still describes the superseded **always-review** model: PSG §11.5's flow ends
"Acceptance Recorded in Review Decision," PSG §13A/§13B and AOG §3.6/§3.7 say the parent "issues
Review Decisions," and both starter templates carry "Stage 2: … issue Review Decisions." The written
model contradicts the operating model. Make them agree — and preserve human review.

### The model to codify
- **Happy path (default-accept):** a parent chat accepts a **clean** child delivery (meets DoD +
  acceptance criteria + spec) **by silence** — **no** Review Decision artifact; the **merge +
  in-chat acknowledgment** is the acceptance record.
- **Exception path:** a **Review Decision** (and, at Epic level, the Epic Review Seal) is issued
  **only when a delivery is not clean** (reject / accept-with-follow-ups).
- **Gate it governs:** the **parent-chat → child** acceptance gate (Phase accepts a clean Milestone;
  Milestone accepts a clean Epic; HQ accepts a clean Phase) and the **acceptance-artifact** question.
- **Preserved:** **Layer-8 human review** — available and authoritative; not a rubber stamp; not
  deleted.
