# Epic Delivery Notice — E23.2

**Epic:** E23.2 — Link + metadata binding convention (P6-VC-2)
**Status:** Execution Complete, Delivered to HQ for Review
**Delivery Date:** 2026-06-29

## Execution Summary

Delivered the **second half of M23**: the binding convention that makes E23.1's by-link model
survivable. With the binary out of git, the only thing in git is a **link** — and a bare link rots.
This Epic supplies the **schema** (a link plus four load-bearing metadata fields) and a **defined
placement per level** so the metadata that outlives the link has a home.

Implementation, against the merged by-link `milestone/M23`:

- **`governance/guides/visual-artifacts.md` — new §7 "Binding a visual to an artifact."** Documents
  the five-element **binding schema** (Link + What / Level / State / Description) as a concrete
  labeled block, and the **per-level placement convention** as a table (Creation → `seed.md` Rule 4
  *Visual success*; HQ → `genesis.md` HQ Context Packet; Phase / Milestone / Epic → each spec
  template's *Visual Bindings* section). States explicitly that a binding records a **link, never a
  committed path**, that **State** is a single field carrying the proposed/implemented two-track (a
  level may hold one of each), and that the schema is documented **once** and referenced from each
  template. A dated **Changelog row** for E23.2 was added.
- **Five per-level templates** each given a defined place to record a binding, in each file's house
  style: `seed.md` (Rule 4 prose notes the binding option on *Visual success*), `genesis.md` (an
  *Architecture visual* binding line in the HQ Context Packet), and a `## Visual Bindings` section
  in `phase-spec.md`, `milestone-spec.md`, and `epic-spec.md` (HTML-comment guidance + a labeled
  placeholder block with `Level` pre-filled to the template's level).

**Design calls (within M23's scope):** the binding is represented as a **labeled block** (matches the
spec's recommended form and the templates' placeholder house style); the per-level home in the three
spec templates is a dedicated **`## Visual Bindings` section placed immediately before `## Notes`**
(a consistent anchor present in all three); the genesis home is a bullet in the **HQ Context Packet**
kept tight to preserve the template's <150-line budget.

Scope honored: **documentation only** — no code, no helper change, no upload step; E23.1's by-link
reversal (§4 / AOG §17.5) and all structural-diagram (Mermaid/PlantUML) guidance are untouched.
