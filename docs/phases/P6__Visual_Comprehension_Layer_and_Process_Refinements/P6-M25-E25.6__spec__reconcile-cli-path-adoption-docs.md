# Epic E25.6 — Reconcile the remaining CLI-path adoption docs (P6-GH-11, doc follow-on)

E25.3 aligned `bin/ai-project-init` to write the canonical **`.ai-project/agents/`** path (Option A:

> the CLI **path** claims only and leaves the `hq.agent.md`-vs-`governance.agent.md` filename/identity
> to P6-GH-15.

## Problem Statement

After E25.3, two live guides (`ADOPTION-GUIDE.md`, `cli-usage-guide.md`) still tell adopters the
`ai-project init` CLI writes `.github/agents/`, which it no longer does. An adopter following these
guides would look in the wrong place. This Epic reconciles those guides to the actual behavior (CLI
writes `.ai-project/agents/`; the Copilot copy is manual), completing the doc side of P6-GH-11.
