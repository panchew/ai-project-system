# Epic E25.4 — Reconcile default-accept across reference/protocol/role/diagram docs (P6-GH-10, follow-on)

## Context

E25.2 codified **SN-13 default-accept** in the **normative** governance documents — PSG **§11.6
"Default-Accept (SN-13)"** and the AOG §14 "Default-Accept (SN-13) — Normative" block — and
reconciled the always-review language in PSG §11.5/§12/§13A-B/§1A, AOG §3.6/§3.7, and the two
**fillable** Execution Chat Starter templates. That Epic met its named contract and is **merged**
to `milestone/M25` (PSG v2.3.0, AOG v2.6.0).

During E25.2's Stage-2 review, a comprehensive `governance/`-wide sweep found that the **superseded
always-review model is still taught across the framework's reference, protocol, role, and diagram
documents** — a surface **neither the M25 milestone spec nor E25.2's spec named**. Several of these
carry rules that **directly contradict** default-accept, not merely stale prose: the artifact
protocol's ordering rule *"A Review Decision (Accept) MUST precede a Delivery Notice"*, the roles
doc's *"Cannot merge PR without Review Decision (Accept)"*, and the artifact-flow diagram showing a
Review Decision as the mandatory response to every Completion Notice. Until these are reconciled,
**milestone acceptance criterion #4 ("No codified text contradicts default-accept") is not met.**

This Epic closes that gap. It aligns the **reference tier** to the model E25.2 already codified —
**referencing PSG §11.6 / AOG §14, not restating them** — so no codified text asserts the
Review-Decision-as-mandatory-happy-path. It **preserves** the Review Decision artifact itself (its
definition, template, storage, schema, and the worked **REJECT** examples — all legitimately the
**exception path**), and it treats the **Bugfix Workflow as a deliberate exception** (its 4-hour
Review Decision SLA is intentional given production urgency — kept, and documented as a carve-out,
not converted to silence-accept).

## Problem Statement

E25.2 made the *normative* docs tell the truth, but the *reference tier* still teaches the lie. New
readers of the framework's protocol doc, roles doc, artifact-flow diagram, and reference starters
learn that a Review Decision is the mandatory response to every Completion Notice — and two of those
docs carry hard rules ("Review Decision (Accept) MUST precede a Delivery Notice"; "Cannot merge PR
without Review Decision (Accept)") that contradict default-accept outright. Every regenerated
reference or worked example inherits the superseded model, and milestone criterion #4 cannot be
certified. This Epic aligns the reference tier to §11.6/§12 — reconciling the mandatory-Review-
Decision assertions to default-accept, preserving the artifact and its exception-path (REJECT)
examples, and documenting the Bugfix Workflow as the one deliberate exception.

## Goals

By the end of this Epic, the system must:

1. **Reconcile every reference-tier assertion of Review-Decision-as-mandatory** (the surfaces named
   above) to **default-accept** — a clean child delivery is accepted by silence; a Review Decision
   is the **exception path** — each **referencing** PSG §11.6 / AOG §14, not restating them.
2. **Reconcile the two hard contradictions:** the artifact-protocol ordering rule ("Review Decision
   (Accept) MUST precede a Delivery Notice") and the roles rule ("Cannot merge PR without Review
   Decision (Accept)") so they describe default-accept (a clean delivery merges by silence; the
   Review Decision precedes merge **only on the exception path**).
3. **Preserve the Review Decision artifact** — its definition, template, schema, storage, and the
   worked **REJECT** examples (the exception path). Do not delete or redefine the artifact.
4. **Document the Bugfix Workflow as a deliberate exception** — keep its explicit Review Decision
   (4-hour SLA); add a short carve-out note (referencing §11.6) that bugfix always issues a Review
   Decision by design. Do **not** convert bugfix to silence-accept.
5. **Bump the versioned reconciled docs** (`artifact-communication-protocol` v1.0.0→v1.1.0,
   `roles-authorization` v1.0.0→v1.1.0, `bugfix-epic-workflow` v1.1.0→v1.2.0) with Changelog rows;
   leave unversioned docs unbumped; **do not re-bump PSG/AOG**.
6. **Grep-prove** no reference-tier text still asserts Review-Decision-as-mandatory, and **keep the
   full test suite green.**
