### Summary

Complete VA-1 on top of E22.1's merged config layer: add a "Visual Artifact Production" section to
AOG, elicit visual intent in `seed.md` Rule 4, ship a `bin/ai-project-visual` ComfyUI helper, write
`governance/guides/visual-artifacts.md`, and add an integration test that **skips when
`visual_artifacts.enabled` is `false`** (the repo default) so the suite stays green without a live
endpoint.

### Problem Statement

E22.1 made visual artifacts *configurable* but nothing yet *uses* the config. Agents have no
guidance on what visual their chat level produces; adopters are never asked what success looks like
visually; there is no callable prompt→artifact path; and there is no guide or test. This Epic
closes that gap.

### Goals

1. **AOG section** — per-level abstraction (SN-11 table), structural vs. generative modes,
   tool-capability gating, what to commit where; opt-in gating on `visual_artifacts.enabled`.
2. **`seed.md` Rule 4** — elicit "What does success look like visually?" before the Project Brief
   (additive, no renumber).
3. **`bin/ai-project-visual`** — callable by any tool-capable agent; reads `comfyui_url`/`enabled`;
   prompt + type + output path → artifact; fails clearly when disabled/unconfigured.
4. **`governance/guides/visual-artifacts.md`** — endpoint config, structural tooling, output formats,
   a worked example per chat level.
5. **Integration test** — exercises the helper; **skips when `enabled: false`**; suite green.
