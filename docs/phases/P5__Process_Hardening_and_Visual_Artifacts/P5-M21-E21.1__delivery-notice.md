# Epic Delivery Notice — E21.1

**Epic:** E21.1 — Platform agnosticism
**Status:** Execution Complete, Delivered to HQ for Review
**Delivery Date:** 2026-06-27

## Execution Summary

Closed GH-5: decoupled governance agent delivery from the GitHub Copilot `.github/agents/`
convention. Defined a **tool-neutral canonical path** — `.ai-project/agents/governance.agent.md`
(consistent with the existing `.ai-project/` namespace used for `artifacts/`, `logs/`, `queue/`) —
and documented it as canonical across every adoption-facing guide. Added four per-tool integration
guides (Claude Code, Cursor, Windsurf, GitHub Copilot) plus an index, each answering the same three
questions in the same order: where the agent lives, how the tool consumes it, how to open a
governance chat. Copilot is preserved as a first-class peer with its `.github/agents/`
auto-detection specifics (and troubleshooting) relocated into its own guide — never deleted, never
demoted below peer status.

Edits were additive and surgical: the host guides were not restructured. Where a guide depicts the
`ai-project init` CLI output (which genuinely still writes `.github/agents/`), the depiction was
kept truthful and annotated to point at the neutral canonical path — the CLI itself was not edited
(out of scope).
