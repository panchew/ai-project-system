## Notes

- **Helper name:** `bin/ai-project-visual` (the recommended name).
- **How the test skips:** it reads the effective `visual_artifacts` config through E22.1's resolver
  (orchestrator loaded via `SourceFileLoader`, mirroring `tests/test_visual_artifacts_config.py`) and
  `pytest.mark.skipif`s the endpoint test when `enabled` is false. Two offline gate tests
  (disabled → exit 2; unconfigured type → exit 3) run unconditionally and pass.
- **Manual endpoint verification:** not performed — no live ComfyUI endpoint is configured in the
  source repo (endpoint availability is the CFO's responsibility, per the SN-11 framework/CFO split).
  Failure modes were verified manually: disabled → exit 2, unconfigured type / video-without-workflow
  → exit 3, unreachable endpoint (`http://127.0.0.1:1`) → exit 4.
- **Stdlib-only:** the helper uses `urllib` (no new dependency; the repo has no `requests`).
- **Default workflow:** a standard txt2img graph is built in for image types; `video` and any bespoke
  pipeline require a `--workflow` graph (prompt injected at the `%prompt%` placeholder).
- **No config-layer changes:** E22.1's `ai-project-yml-spec.md`, validator, and `.ai-project.yml`
  were consumed read-only.
