## Execution Summary

Closed GH-9 (the final M20 epic) by documenting the hierarchical communication protocol from
SN-12b as binding governance. The four binding decisions — upward communication is 1-to-1
(one level at a time, no skipping to a grandparent); downward communication is the spec file
rather than broadcasting (one write, many readers); the level spec file is dual-role
(planning artifact + live contract); and mid-flight updates escalate UP rather than reaching
into running child sessions — are now stated in `chat-hierarchy.md`, AOG §3.10, and PSG §13D,
with amendment-issuing guidance added to both the Phase and Milestone Execution Chat Starter
templates.

All edits are additive — new sections/rules/bullets inserted in each host document's existing
style, no host content restructured or reflowed. The decisions are transcribed faithfully
from the spec and source steering note, neither softened nor extended. Consistent with the
E20.2–E20.4 convention, no document version or changelog was bumped.
