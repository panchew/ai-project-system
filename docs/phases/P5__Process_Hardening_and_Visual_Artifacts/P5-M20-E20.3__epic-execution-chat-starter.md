## Epic Specification

**Authoritative source:** `docs/phases/P5__Process_Hardening_and_Visual_Artifacts/P5-M20__milestone-spec.md` (§ "Epic Detail → E20.3")

### Summary

Close GH-3: document the HQ-ratified mandatory channel for scope direction to in-flight
Epics, so scope never changes without an audit trail and a spec amendment.

### Problem Statement

CFO / Creation Chat scope direction to an in-flight Epic had no documented mandatory
channel. Direction could reach an Epic informally, changing scope with no Steering Note,
no spec amendment, and no re-issued starter — leaving no audit trail and inviting ambiguity.

### Goals

1. Add a "Scope Direction Protocol" section to `governance/systems/chat-hierarchy.md`
   containing the HQ-ratified rule **verbatim**, the P0 exception, and a one-paragraph
   rationale.
2. Add a corresponding rule to `governance/AI-OPERATING-GUIDELINES.md` §3 that references
   the routing requirement.

---

## Required Content — RATIFIED RULE (must appear VERBATIM)

The "Scope Direction Protocol" section in `chat-hierarchy.md` must contain this rule
exactly as written — do not paraphrase, soften, reorder, or extend it:

> Scope direction from the Creation Chat or CFO (Layer 8) to any in-flight Epic must
> flow as Steering Note → HQ Chat → spec amendment → Milestone Chat re-issues amended
> starter. The only exception is a P0 production emergency, where an unblocking directive
> may be issued verbally and formalized within the same session via a Steering Note and
> retroactive spec amendment.

In addition to the verbatim rule, the section must include:
- The **P0 exception** called out explicitly (already in the rule; present it clearly).
- A **one-paragraph explanation** of why the channel matters: it preserves an audit trail
  (every scope change is traceable to a Steering Note and a spec amendment) and prevents
  ambiguity (an Epic only ever executes against its committed, re-issued starter).

The AOG §3 addition must state the routing requirement and cross-reference the
`chat-hierarchy.md` "Scope Direction Protocol" section.
