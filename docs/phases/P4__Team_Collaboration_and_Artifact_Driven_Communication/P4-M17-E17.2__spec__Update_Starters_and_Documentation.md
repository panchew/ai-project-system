# Epic P4-M17-E17.2: Update Starters and Documentation

## Problem Statement

The HQ Chat Starter and Milestone Chat Starter were written before P4 (Team
Collaboration, Artifact-Driven Communication) completed. They do not reference the
artifact system, team role governance, production deployment gate, or the example
project created in M16. New teams adopting the system must read multiple separate
governance documents to piece together the full workflow.

Additionally, three governance artifact types — Merge Authorization, Epic Closure
Notice, and Escalation Notice — have been used in practice (M15, M16) but have no
canonical template in `governance/templates/`. The gap forces each Chat to invent
formatting on the fly and produces inconsistent artifacts across milestones.

This Epic closes all of these gaps: updated starters, new index and FAQ documents,
missing templates, and a pre-commit lint check that catches the `M14x`-style
branch-name typos that have recurred across M15 and M17.

## Design

### Template Front-Matter Schema (all three new templates)

```yaml
---
type: <merge-authorization | epic-closure-notice | escalation-notice>
epic: <P#-M#-E#.#>          # omit for escalation-notice
milestone: <M##>
issued_by: <role and chat name>
issued_to: <role and chat name>
date: <YYYY-MM-DD>
status: <authorized | complete | open | resolved>
---
```

### Lint Check Strategy

The lint check is a pytest test that:
1. Scans all `*epic-execution-chat-starter.md` files under `docs/`
2. Parses the `milestone:` field from the file's YAML front-matter
3. Searches the file body for `` `milestone/M`` patterns
4. Flags any occurrence where the milestone number does not match the front-matter
   value (e.g., front-matter says M17 but body contains `milestone/M147`)

Placed in `tests/test_starter_lint.py`.
