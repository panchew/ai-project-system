# Epic P4-M1-E1.3: Integration Tests for Multi-Artifact Workflows

## Problem Statement

E1.1 provides artifact parsing, E1.2 provides daemon routing. But we need end-to-end integration tests to ensure the full artifact workflow operates correctly:

1. Epic completes and produces Completion Notice
2. Daemon routes to Milestone Chat
3. Milestone Chat reviews and produces Review Decision
4. Daemon routes Review Decision back to Epic Chat
5. Epic Chat processes Accept decision and merges PR
6. Epic Chat produces Delivery Notice
7. Daemon routes to Milestone for acknowledgment

Without integration tests, we risk subtle bugs in the hand-off between chats and daemon.

---

## Requirements

### Functional Requirements

1. **End-to-End Workflow Tests**
   - Test complete cycle: Completion → Review Decision (Accept) → Delivery
   - Test rejection cycle: Completion → Review Decision (Reject) → Rework → new Completion (v1.1) → Accept
   - Test escalation: Completion → escalate to Phase Chat → Phase reviews → Review Decision
   - Test artifact aggregation: Multiple Epics complete → Milestone aggregates into Milestone Completion Notice

2. **Manual Mode Tests**
   - Verify artifacts can be copy-pasted between chats (format is copy-paste friendly)
   - Verify both agentic and manual modes coexist in same queue directory
   - Verify artifact content integrity across manual copy-paste

3. **Agentic Mode Tests**
   - Verify daemon correctly routes Completion Notice to parent chat
   - Verify parent chat receives artifact with correct epic_id, milestone_id references
   - Verify Review Decision routed back to Epic Chat
   - Verify Delivery Notice routed to parent for acknowledgment

4. **Error Scenario Tests**
   - Test rejection with feedback (Epic must rework specific items)
   - Test escalation (Milestone cannot decide, escalates to Phase)
   - Test SLA timeout (Review not completed within 4 hours for bugfix)
   - Test artifact corruption (malformed YAML, missing fields)

5. **Parallel Execution Tests**
   - Multiple Epics executing concurrently
   - Multiple artifacts being routed simultaneously
   - No race conditions or lost artifacts

### Non-Functional Requirements

- **Coverage:** 95%+ code coverage for artifact parsing and routing
- **Performance:** Full workflow completes in <5 seconds (including 3-attempt Dev-QA loop simulation)
- **Reliability:** All tests pass consistently (no flaky tests)
- **Maintainability:** Clear test structure, reusable fixtures, well-documented

### Test Scenarios

#### Scenario 1: Happy Path (Accept & Deliver)
```
1. Epic Agent completes work
   → Produces Completion Notice (artifact_v1.0)
   
2. Daemon detects Completion Notice
   → Routes to Milestone Chat (creates trigger)
   
3. Milestone Agent reads Completion Notice
   → Reviews (simulated in test)
   → Issues Review Decision (ACCEPT)
   
4. Daemon detects Review Decision
   → Routes back to Epic Agent
   
5. Epic Agent reads Accept decision
   → Merges PR (simulated)
   → Produces Delivery Notice
   
6. Daemon detects Delivery Notice
   → Routes to Milestone for acknowledgment
   
7. Verify: All artifacts in place, no errors
```

**Test Code Skeleton:**
```python
def test_artifact_happy_path(tmp_project):
    """Complete workflow: Completion → Accept → Delivery"""
    # 1. Create Completion Notice in .ai-project/artifacts/completion-notices/
    completion_notice = create_completion_notice(tmp_project, epic_id="P1-M1-E1.1")
    
    # 2. Run daemon artifact routing (simulated or actual)
    daemon.process_artifacts(tmp_project)
    
    # 3. Verify Completion Notice routed (trigger created for Milestone)
    assert_file_exists(tmp_project, '.ai-project/queue/route_completion_P1-M1-E1.1.json')
    
    # 4. Simulate Milestone Chat reviewing and issuing Review Decision
    review_decision = create_review_decision(tmp_project, epic_id="P1-M1-E1.1", decision="accept")
    
    # 5. Run daemon routing again
    daemon.process_artifacts(tmp_project)
    
    # 6. Verify Review Decision routed back to Epic
    assert_file_exists(tmp_project, '.ai-project/queue/route_review_decision_P1-M1-E1.1.json')
    
    # 7. Simulate Epic Agent processing Accept and merging
    delivery_notice = create_delivery_notice(tmp_project, epic_id="P1-M1-E1.1")
    
    # 8. Run daemon routing
    daemon.process_artifacts(tmp_project)
    
    # 9. Verify Delivery Notice routed to Milestone
    assert_file_exists(tmp_project, '.ai-project/queue/route_delivery_P1-M1-E1.1.json')
    
    # 10. Verify audit trail complete
    assert_all_artifacts_processed(tmp_project)
```

#### Scenario 2: Rejection & Rework
```
1. Epic Agent produces Completion Notice (v1.0)
2. Daemon routes to Milestone
3. Milestone Agent issues Review Decision (REJECT with feedback)
4. Daemon routes back to Epic
5. Epic Agent reworks based on feedback
6. Epic Agent produces new Completion Notice (v1.1)
7. Daemon routes to Milestone
8. Milestone Agent issues Review Decision (ACCEPT)
9. Artifact workflow continues...

Verify: v1.0 marked as rejected, v1.1 treated as new submission
```

#### Scenario 3: Escalation
```
1. Epic at E1.1 produces Completion Notice
2. Daemon routes to Milestone Chat (M1)
3. Milestone cannot decide (ambiguous issue) → escalates
4. Daemon detects Escalation artifact
5. Routes to Phase Chat (P1)
6. Phase Chat reviews and issues Review Decision
7. Daemon routes back to Milestone
8. Milestone forwards to Epic
9. Epic processes decision...

Verify: Escalation path works, no artifacts lost
```

#### Scenario 4: Manual Mode
```
1. Epic produces Completion Notice (markdown file)
2. Human copy-pastes Completion Notice into Milestone Chat
3. Milestone Chat reads artifact (from message content)
4. Milestone produces Review Decision (human copy-paste)
5. Human pastes Review Decision into Epic Chat
6. Epic Chat reads decision...

Verify: Artifact format is copy-paste friendly (no special characters, clear structure)
```

#### Scenario 5: Parallel Execution
```
Create 5 concurrent Epics in same Milestone:
- E1.1, E1.2, E1.3, E1.4, E1.5
Each produces Completion Notice within 100ms of each other

Daemon must:
- Route all 5 to Milestone without dropping any
- Maintain correct epic_id in each routing trigger
- No race conditions or corrupted routing

Verify: All 5 artifacts routed correctly
```
