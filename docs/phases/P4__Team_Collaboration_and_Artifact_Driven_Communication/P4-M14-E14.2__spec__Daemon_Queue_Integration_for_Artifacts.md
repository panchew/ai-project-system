# Epic P4-M14-E14.2: Daemon Queue Integration for Artifacts

## Problem Statement

The daemon currently monitors `.ai-project/queue/` for trigger files (04_epic.json) and spawns the orchestrator. It does not handle artifact files (Completion Notices, Review Decisions, Delivery Notices).

We need the daemon to:
1. Detect when Completion Notice artifacts are written
2. Route them to parent chats (Milestone or HQ)
3. Detect Review Decision artifacts and route back to child chats
4. Handle the bidirectional artifact flow without file race conditions

---

## Requirements

### Functional Requirements

1. **Monitor Artifact Directories**
   - Extend daemon to monitor `.ai-project/artifacts/completion-notices/`
   - Extend daemon to monitor `.ai-project/artifacts/review-decisions/`
   - Extend daemon to monitor `.ai-project/artifacts/delivery-notices/`
   - Detect new files and process them

2. **Parse & Route Completion Notices**
   - Read Completion Notice from `completion-notices/` directory
   - Parse using artifact parser from E14.1
   - Extract epic_id, milestone_id, phase_id
   - Determine parent: if milestone_id exists → Milestone Chat; if phase_id only → HQ Chat
   - Create routing trigger for parent chat
   - Move processed artifact to `completion-notices/.processed/`

3. **Route Review Decisions Back to Epic Chat**
   - Read Review Decision from `review-decisions/` directory
   - Parse using artifact parser
   - Extract epic_id (or milestone_id for Milestone-level decisions)
   - Create routing trigger for Epic Chat (or Milestone Chat if Milestone-level)
   - Move processed artifact to `review-decisions/.processed/`

4. **Route Delivery Notices for Acknowledgment**
   - Read Delivery Notice from `delivery-notices/` directory
   - Parse and extract parent reference
   - Route to parent chat for acknowledgment
   - Move to `delivery-notices/.processed/`

5. **Handle Race Conditions**
   - Use file locking to prevent reading incomplete files
   - Wait for file write to complete before processing
   - Idempotent processing: if same artifact processed twice, don't route twice
   - Handle file deletion or moves gracefully

6. **Status Logging**
   - Log all artifact processing events
   - Log routing decisions (which parent chat receives Completion Notice)
   - Log errors (parse failures, routing failures)
   - Maintain audit trail in daemon logs

### Non-Functional Requirements

- **Performance:** Route artifact within 1 second of detection
- **Reliability:** No data loss; all artifacts accounted for
- **Scalability:** Handle 10+ artifacts per second (burst during M14 milestones)
- **Safety:** No race conditions; idempotent processing

## Design

### Daemon Extensions

**Current Daemon Loop (P3):**
```
while True:
    1. Check .ai-project/queue/ for 04_epic.json files
    2. Process trigger: spawn orchestrator
    3. Sleep 30 seconds
```

**Extended Daemon Loop (P4):**
```
while True:
    1. Check .ai-project/queue/ for 04_epic.json files (existing)
    2. Check .ai-project/artifacts/completion-notices/ for new files (NEW)
    3. Check .ai-project/artifacts/review-decisions/ for new files (NEW)
    4. Check .ai-project/artifacts/delivery-notices/ for new files (NEW)
    5. Process each type (existing + NEW routing logic)
    6. Sleep 10 seconds (faster to catch artifacts)
```

### Artifact Routing Mechanism

**Option A: Write to Upstream Queue**
- When daemon detects Completion Notice for epic P1-M14-E14.1
- Write trigger to parent queue: `.ai-project/queue/03_milestone.json` (or equivalent for parent)
- Parent chat (Milestone Agent) processes trigger and reads artifact from `.ai-project/artifacts/`

**Option B: Write to Shared Queue with Routing**
- Create shared `.ai-project/artifacts_ready_for_review/` directory
- Daemon moves processed artifact here
- Parent chat polls this directory
- Parent issues Review Decision back to `.ai-project/artifacts/review-decisions/`

**Recommendation: Option A** (reuse existing queue mechanism, simpler)

### File Locking Strategy

```python
def process_artifact_file(filepath):
    # 1. Try to acquire lock (not exclusive, read-lock)
    # 2. Wait up to 1 second for lock (file may still be writing)
    # 3. Read file contents
    # 4. Release lock
    # 5. Process (parse, validate, route)
    # 6. Move to .processed/ directory
```

**Implementation:**
- Use `fcntl.flock()` on Unix/Linux (non-blocking mode, timeout)
- Use `msvcrt.locking()` on Windows
- Or: Use `.tmp` file convention (write to `.tmp`, then rename on complete)

### Pseudocode

```python
class ArtifactRouter:
    def route_completion_notice(self, artifact: Artifact):
        """Route Completion Notice to parent chat."""
        epic_id = artifact.frontmatter['epic_id']
        milestone_id = artifact.frontmatter.get('milestone_id')
        phase_id = artifact.frontmatter.get('phase_id')
        
        # Determine parent
        if milestone_id:
            parent = 'milestone'
            parent_ref = milestone_id
        elif phase_id:
            parent = 'phase'
            parent_ref = phase_id
        else:
            parent = 'hq'
        
        # Create routing trigger
        trigger = {
            'action': 'route_artifact',
            'artifact_type': 'completion_notice',
            'artifact_path': str(artifact.filepath),
            'epic_id': epic_id,
            'parent': parent,
            'parent_ref': parent_ref,
            'timestamp': artifact.frontmatter['timestamp']
        }
        
        # Write trigger to queue
        trigger_path = QUEUE_DIR / f"route_completion_{epic_id}.json"
        write_json(trigger_path, trigger)
        
        # Move artifact to processed
        processed_path = artifact.filepath.parent / '.processed' / artifact.filepath.name
        artifact.filepath.rename(processed_path)

def daemon_artifact_monitoring_loop():
    """Extended daemon loop for artifact monitoring."""
    artifact_dirs = [
        '.ai-project/artifacts/completion-notices',
        '.ai-project/artifacts/review-decisions',
        '.ai-project/artifacts/delivery-notices'
    ]
    
    for artifact_dir in artifact_dirs:
        for artifact_file in artifact_dir.glob('*.md'):
            # Skip if in .processed/
            if '.processed' in artifact_file.parts:
                continue
            
            try:
                # Parse artifact
                artifact = parser.parse_file(artifact_file)
                
                # Route based on type
                if artifact.type == 'completion_notice':
                    router.route_completion_notice(artifact)
                elif artifact.type == 'review_decision':
                    router.route_review_decision(artifact)
                elif artifact.type == 'delivery_notice':
                    router.route_delivery_notice(artifact)
                
            except Exception as e:
                logger.error(f"Failed to process {artifact_file}: {e}")
                # Move to .failed/ for manual review
                failed_path = artifact_file.parent / '.failed' / artifact_file.name
                artifact_file.rename(failed_path)
```
