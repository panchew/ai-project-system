### Phase 1: docs/bugfixes/ and B#.# Convention (Day 1 AM)

  conventions before inventing new ones; use whatever is already there
- Document: naming format, severity mapping, required spec fields, location

### Phase 2: HQ Chat Starter Bugfix Section (Day 1 PM)
Update `governance/systems/hq-execution-chat-starter.md`:
- Add section: "Handling Production Issues (Bugfix Epics)"
- Six steps: evaluate → create B#.# spec → commit to docs/bugfixes/ → issue Delivery
  Authorization → track 4-hour SLA → escalate on miss

Create `governance/templates/deployment-authorization.md`:

- YAML schema (type, epic, severity, incident_date, resolved_date, authored_by)

### Phase 5: Carry-Overs and Phase Spec (Day 3)
