### Summary

Delete 7 stale or obsolete files from master, rewrite `governance/systems/start-a-project.md`
to reflect the current project initialization flow, update the P4 phase spec to use global
M15–M20 milestone numbering, and deliver a recommendation on renaming the canonical

Master contains five M1-nomenclature planning artifacts that present M14's completed work

template is canonical, a `start-a-project.md` that describes a superseded manual setup
flow, and a P4 phase spec that uses local M1/M2/M3/M4 numbering instead of the correct
global M15–M20. Together these make master misleading about both project state and
how to onboard a new project.

### Goals

1. Remove all 5 M1-nomenclature planning artifacts from the P4 phase folder
2. Remove 2 obsolete completion templates from `governance/templates/`
3. Rewrite `governance/systems/start-a-project.md` to describe the current
   `ai-project init` + governance-as-submodule flow, including the Creation Chat / Genesis
   layer
4. Update `P4__phase-spec.md` to replace M1/M2/M3/M4 with M15–M20 and reflect expanded scope
5. Deliver a clear recommendation (yes/no with rationale) on renaming
   `governance/templates/completion-notice-epic.md` to `completion-notice.md`
