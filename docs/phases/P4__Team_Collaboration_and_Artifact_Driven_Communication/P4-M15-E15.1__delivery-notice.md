## Rename Recommendation: `completion-notice-epic.md`

**Recommendation:** Keep current name `completion-notice-epic.md`.

**Rationale:** Although the template's own text states it "applies at all levels," the
current governance practice consistently uses it at the Epic level only; Milestone and Phase
closures use `milestone-closure-declaration.md` and their own closing artifacts. Renaming
to `completion-notice.md` would break existing references in `governance/PROJECT-SYSTEM-GUIDELINES.md`
(line 514) and `governance/templates/README.md` (3 references) without a corresponding
update sweep — that update sweep is out of E15.1 scope and warrants its own Epic. The
level-specific name also makes the template directory self-documenting: a reader immediately
knows which artifact goes with which lifecycle stage. If a rename is desired in a future
Epic, a comprehensive reference update should accompany it.
