## Epic Specification

**Full spec:** `docs/phases/P4__Team_Collaboration_and_Artifact_Driven_Communication/P4-M16-E16.1__spec__Example_Project_Setup_and_Walkthrough.md`

### Summary

Create a realistic 3-person team example project under `examples/team-project-example/`
with a full Phase → Milestone → Epic structure, team role assignments, sample artifacts
(Completion Notices, Review Decisions, Delivery Notices), and a step-by-step walkthrough
of one complete Epic cycle from planning to delivery.

### Problem Statement

New teams adopting the AI Project System have no hands-on example to reference. Reading
governance documents explains the theory, but without a concrete example — real artifact
files, team assignments, and decision points — teams must guess how to apply the system
in practice. This Epic provides a ready-to-run reference project that makes the workflow
tangible.

### Goals

1. Create `examples/team-project-example/` with a realistic Phase P1 structure (3
   Milestones, 6–9 Epics)
2. Define 5 team roles (CFO, Phase Lead, Developer 1, Developer 2, Reviewer) with
   explicit decision authorities
3. Populate `.ai-project/artifacts/` with valid sample Completion Notices, Review
   Decisions, and Delivery Notices (3+ of each)
4. Write a step-by-step "One Full Epic from Start to Finish" walkthrough document
   that shows decision points and who decides
5. Validate all artifact YAML with 10+ automated tests
