## Implementation Plan

### Phase 1: Team Onboarding Guide (Day 1 AM)
Create guide covering:
- Role definitions: CFO, Phase Lead, Contributor, Reviewer, agents
- Authority matrix: who decides what (table format)
- Escalation flowchart: when to escalate, to whom
- Communication norms: chat-first, artifact-driven
- Time commitment per role
- How to read artifacts (Completion Notice, Review Decision, etc.)

### Phase 2: CFO Quick Start (Day 1 PM)
Create short, actionable guide:
- Your job: 3-5 bullet points
- Typical week: 1-3 decisions per project
- How to review Completion Notices (steps)
- How to issue Review Decisions (steps)
- How to authorize production deployment (steps)
- Time commitment: 30 min - 2 hours/week
- Example: walk through one decision

### Phase 3: Contributor Guide (Day 2 AM)
Create detailed workflow guide:
- Your job: implement Epics
- Epic workflow: receive spec → implement → Completion Notice → await decision → merge
- Definition of Done: tests, documentation, code review
- What to ask if blocked (escalation guide)
- Example PR workflow
- Common questions: "What if my tests fail?" "Can I modify the spec?" etc.

### Phase 4: Reviewer Guide (Day 2 PM)
Create code review guide:
- Your job: code review and DoD validation
- Review checklist: tests passing, coverage, docs, spec compliance
- How to provide feedback (tone, clarity)
- How to block merge if needed
- Integration with Review Decision process
- Example review comments

### Phase 5: Phase Lead Guide (Day 3 AM)
Create leadership guide:
- Your job: milestone coordination
- Milestone planning: breaking down Phase into Milestones and Epics
- Prioritization: how to sequence Epics
- Escalation: when and how to escalate to CFO
- Delegation: working with Milestone Agents
- Team communication: daily standup patterns

### Phase 6: Decision Matrices (Day 3 PM)
Create reference tables:
- Phase scope: who decides (CFO), criteria for approval
- Milestone planning: who decides (Phase Lead or HQ Agent)
- Epic acceptance: who decides (Milestone Agent), review criteria
- Production deployment: who decides (CFO), approval criteria
- Escalation: trigger points and routing

### Phase 7: Example Walkthrough (Day 4 AM)
Create step-by-step walkthrough:
- Reference E16.1 example project
- Show one full Epic cycle: planning → E14.1 assignment → implementation → Completion Notice → review → merge → Delivery Notice
- Highlight decision points and who decides
- Show artifacts flowing between chats
- Both manual mode (copy-paste) and agentic mode (daemon)

### Phase 8: FAQ & Troubleshooting (Day 4 PM)
Create reference docs:
- FAQ: "How do I...?" style (10+ questions)
- Troubleshooting: common issues and solutions
- Cross-link all guides

## Content Guidelines

### CFO Quick Start
- **Tone:** Direct, actionable, no fluff
- **Length:** <2 pages, <1000 words
- **Structure:** Your job → typical week → example decision → time commitment
- **Example:** "You review one Completion Notice (takes 5 minutes). You approve it. Done."

### Contributor Guide
- **Tone:** Supportive, clear, practical
- **Length:** 2-3 pages
- **Structure:** Your job → epic workflow → DoD → questions → examples
- **Example:** "If your tests fail, fix them and resubmit Completion Notice. Don't worry, we have 3 attempts."

### Decision Matrices
- **Format:** Tables with rows (decision types) and columns (who decides, criteria, timing)
- **Tone:** Reference, no narrative
- **Completeness:** Every decision type has a row

### Troubleshooting
- **Format:** Problem → Cause → Solution (Q&A style)
- **Tone:** Helpful, no blame
- **Coverage:** Known issues from P4 design, common user questions
