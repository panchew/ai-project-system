## Epic Specification

**Full spec:** `docs/phases/P4__Team_Collaboration_and_Artifact_Driven_Communication/P4-M16-E16.2__spec__Team_Collaboration_Documentation.md`

**Dependency:** E16.1 must be merged to `milestone/M16` before this Epic begins.
`examples/team-project-example/` must be accessible on `milestone/M16`.

### Summary

Create comprehensive role-based collaboration guides — Team Onboarding Guide, CFO Quick
Start, Contributor Guide, Reviewer Guide, Phase Lead Guide, Decision Matrices, and an
Example Walkthrough — that enable any new team member to understand their role, decision
authority, and workflow within 30 minutes of reading.

### Problem Statement

The AI Project System was designed for solo development. Adopting it as a team requires
explicit role definitions, clear authority boundaries, and lookup-ready decision matrices.
Without these, teams will encounter authority conflicts, unclear escalation paths, and low
adoption rates. This Epic produces the documentation that makes team adoption practical.

### Goals

1. Write concise, role-specific guides for CFO, Contributor, Reviewer, and Phase Lead
2. Produce an authority matrix that answers "who decides?" in under 30 seconds
3. Create a full-cycle example walkthrough using the E16.1 example project artifacts
4. Demonstrate both manual (copy-paste) and agentic (daemon routing) execution modes
5. Cross-link all guides and surface them from the main docs README
