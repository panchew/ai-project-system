## 6. The overpack cannot recur — structurally, and a reviewer can check it

**[drivr]** The guarantee is not "the adapter is careful." It is that **the package names neither
the trained-maximum endpoint nor its value anywhere in its source**, enforced by two tests:

```
$ grep -rn "api/show" drivr/ ; echo "exit=$?"
exit=1                                  # no matches

$ grep -rn "262144" drivr/ ; echo "exit=$?"
exit=1                                  # no matches
```

`tests/test_context_limits.py::test_package_never_references_the_trained_maximum_endpoint` and
`::test_package_never_hardcodes_the_trained_maximum_value` fail the build if either appears.
**A future adapter cannot copy the wrong endpoint from this codebase, because it is not in it.**

The **empty** case is covered by `::test_empty_api_ps_yields_unobserved_rather_than_a_fallback`,
and the failure mode is explicit: `UNOBSERVED.value is None`, and the adapter then **removes**
the declaration from the config copy it hands the engine rather than letting the user's stock
declaration stand.

> **Constraint 10, hit and handled during this Epic.** The first draft of `context_limits.py`
> cited both the endpoint and the number in its own docstring **while explaining that neither may
> be used** — it would have failed the very test it was introducing. The literals now live in the
> documentation and in the tests that forbid them. *A document that records having fixed a defect
> is liable to restate the defect while doing so.*

## 12. `opencode serve` — recorded for E38.4

**Unused by this adapter, recorded because E38.4 inherits it.** Measured on the host:

- `opencode serve` — *"starts a headless opencode server"*.
- `--port` (default `0`, random), `--hostname` (default `127.0.0.1`), `--cors` (array),
  **`--mdns`** (mDNS discovery; **defaults hostname to `0.0.0.0`** — a listener exposure worth
  knowing before it is enabled), `--mdns-domain` (default `opencode.local`).
- **The pairing E38.4 will care about:** `opencode run --attach <url>` attaches a one-shot run to
  a running server, with `-s/--session`, `-c/--continue`, `--fork` for continuation. **That is
  the closest OpenCode analogue to `local-agent-runner`'s library entry point**, which is one of
  the two named retention candidates.
- Also present: `opencode acp` (*"start ACP (Agent Client Protocol) server"*),
  `opencode export <sessionID>` / `opencode import`.

**Why this adapter uses one-shot `run`:** a long-lived server is state, and an adapter that
invokes an engine and reports what came back has no reason to own any. **This is not a finding
against `serve`** — it is untested here, and E38.4 owns that assessment.
