## Notable Findings for the Milestone Chat

1. **`S1`'s grep has a blind spot, which in this instance hid nothing — checked, not assumed.**
   The spec's S1 command filters `--include='*.py'`, and this fleet's `bin/` executables are Python
   **without a `.py` extension** — so none of them are scanned. `drivr/bin/drivr-serve` is the file
   that prompted the check, since a file called *serve* is exactly what an "is there an HTTP
   surface?" measurement must not miss.

   Re-run **without** the extension filter, `bin/drivr-serve` matches **0** of the five patterns: it
   is E40.1's scheduler, and the name is about serving the lane, not serving HTTP. **S1's conclusion
   therefore stands on evidence rather than on the filter having been lucky.** The blind spot itself
   is real and will outlive this epic — an extension-filtered sweep for *any* property will skip
   every `bin/` entry point in this fleet.

   Post-delivery, the same unfiltered sweep returns exactly four files, all added by this epic:
   `drivr/surface/app.py` and three test files.
2. **Two vacuous results, found and corrected before capture.** The first live run failed at every
   step (`drivr-gate` lacked the executable bit; every `curl` returned `000`); the second's `GET`
   went to a closed port, so *"the spend log does not exist, therefore `GET` spent nothing"* was
   **true and worthless** — it would have read identically with the guard absent. **An absence is
   only evidence when the thing that would have created it actually ran.** Offered as a candidate
   method obligation.
3. **One falsification is weaker than its number suggests, and is reported as such.** Widening
   `ACCEPTED_FIELDS` breaks exactly **1** test, because that constant is a tripwire on a
   *declaration* — the enforcement is that the parsers ask for `t` by name. Reported rather than
   presented as a sixth clean pass.
4. **The prior art at `lib/artifact_router.py` should not be reused for anything approval-shaped.**
   `IdempotencyTracker` is check-then-act and `_save()` swallows all exceptions. Both are reasonable
   for artifact routing and are defects for authorization. **Not filed as a `GH-` ID** (obligation 4,
   and `P11-GH-3` is contested) — raised here for the Milestone Chat's disposition.
5. **A self-correction, left visible in the evidence.** The per-file test attribution was first
   written from estimates (39/16/27/13) that summed to the correct 95 while being wrong in three of
   four rows. **A total that reconciles is not evidence that its parts do.**
