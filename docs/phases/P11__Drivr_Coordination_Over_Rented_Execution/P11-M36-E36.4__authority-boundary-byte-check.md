## The command

Content-anchored, not line-number-based: this Epic **adds a section to `system-hq.md`**, shifting
every line below it, so a line-number check would break or — worse — silently compare the wrong range
and report a false pass.

```bash
extract() { awk '/^> \*\*System HQ Authority Boundary\.\*\*/{f=1} f{if(/^$/)exit; print}' "$1"; }
for f in governance/systems/system-hq.md \
         governance/systems/system-hq-seed.md \
         governance/systems/chat-hierarchy.md; do
  printf '%s  %s  (%s lines)\n' "$(extract "$f" | sha256sum | cut -c1-16)" "$f" "$(extract "$f" | wc -l)"
done
```

The anchor was verified against all three documents before use — it matches exactly one line per file
(`system-hq.md:61`, `system-hq-seed.md:77`, `chat-hierarchy.md:1077`), and the terminating blank line
closes the block at 11 lines in each.
