### Summary

Build, in Drivr, a completion judgment that answers *"did this run complete?"* from evidence and
returns a **verdict carrying that evidence** — resting on neither the exit code nor `status`, both of
which are measured wrong in both directions. It is a layer **above** `ExecutionResult`, which E38.2
deliberately built as observations with no verdict.

See Epic spec §Problem Statement. In short: every single available signal has been measured wrong on
at least one known case, M35's handback rule has had no detector beneath it since it was recorded,
and M40's scheduler and derived gate queue are gated on this epic delivering.
