## The comparison — what was compared and why its ground truth is knowable

**Material:** E38.3's fleet-registry validation fix (commit `927b7fa`). The task: replace
the single `total_warnings: 14` with distinct fleet-only and raw totals, add derived fields,
and add a test verifying the derived invariants.

## The blinding method, defended

**Method:** E35.5's discipline, adapted — a blinded packet with an audit header and a
`<!-- PROMPT-BEGIN -->` marker (so the prompt is exactly the bytes after the marker), a
pre-registered rubric, and the excised materials named in the packet header.

**Verifiable location:** `.ai-project/artifacts/reference/local-paid-comparison/`.

**The adaptation:** because a local arm with repository access can find a committed answer,
the local arm was run in an **isolated workspace** — a temporary directory containing only
the two pre-fix files, with **no `.git` directory and no post-fix commits**. The paid arm
was run as a manual chat per `models.epic_manual`.

**The blinding was enforced on the local arm and failed on the paid arm** — see §The
asymmetry finding. This asymmetry is stated, not smoothed.
