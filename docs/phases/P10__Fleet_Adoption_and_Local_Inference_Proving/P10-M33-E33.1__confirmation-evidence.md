## Delivery boundary (read this before confirming)

The bump for each project is a **local commit on a dedicated `chore/framework-v7.0.0-bump`
branch**, in the target's working clone on the operator's machine. It is **not pushed to `origin`
and not merged to the target's authoritative branch** — pushing/merging in a CFO-controlled repo is
an **outward action reserved to the project owner (CFO)**, outside E33.1's scope (analogous to how
this epic's own PR merge is human-authorized). The stamp is real and committed *in the target repo*;
confirmation is run against the target working clone. When the CFO pushes/merges these branches, the
same commit refs carry the stamp onto the authoritative branch unchanged.
