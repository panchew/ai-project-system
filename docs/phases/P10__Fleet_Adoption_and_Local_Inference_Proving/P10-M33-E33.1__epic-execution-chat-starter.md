### Summary

Produce a documented, **repeatable** procedure for bumping an enrolled project to v7.0.0
(governance refresh + `framework_version` stamp), and apply it to both proving-pair projects
(`home_finance`, `local-agent-runner`) so each is stamped and confirmable at
`framework_version: v7.0.0`. The procedure is the reusable lever M34 consumes.

### Problem Statement

No project except the framework itself is confirmably on v7.0.0; enrollment across the fleet is
shallow. This Epic bumps the two proving-pair projects and — the load-bearing part — leaves
behind a precondition-complete, failure-mode-documented procedure another operator (or M34) can
re-run against a project it has never touched. See the spec's Problem Statement.

### Goals

1. A documented, repeatable v7.0.0 bump procedure (mechanism, steps, preconditions, failure
   modes, stamp location + confirmation method).
2. Both proving-pair projects bumped and stamped `framework_version: v7.0.0` in their own repos,
   governance refreshed.
3. Confirmation evidence in this repo's governance record so both stamps are verifiable from
   here (Cross-Repo split).
4. Framework-repo suite green for any change touching this repo (363 baseline, no new skips).
