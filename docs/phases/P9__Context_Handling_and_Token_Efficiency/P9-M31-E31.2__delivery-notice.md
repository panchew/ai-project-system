## Design Decisions (spec §Design Decisions, resolved)

1. **Decision logic = (A) traceability-only, not (B) traceability + runtime divergence
   assertion.** `tests/test_model_config.py`'s policy↔block divergence guard (Deliverable 3)
   already catches drift at CI time, before any dispatch happens; a second check inside the
   hot dispatch path would add a runtime dependency on parsing the policy file for no
   additional safety beyond what CI already gates. Hard Constraint 3's "guard logic treats
   divergence as an error" is discharged by the guard *tests*, which is what "guard logic"
   names throughout this Epic's spec.
2. **Local-unavailable handling = (C), both layers.** `bin/run-dev-agent` makes the signal
   distinguishable (exit `5`, before the runner is ever invoked); `handle_epic_execution`
   makes it actionable (immediate refusal + distinguished escalation record, reusing
   `generate_escalation_report` per the spec's own suggested extension point).
3. **Consistency-guard extension = extended the existing file** (not a sibling), covering
   all five keys with a narrow regex-based table parser for the divergence check — matches
   the spec's explicit sanction ("grepping the five key rows is acceptable").
4. **Row-P5 run-evidence location = the existing `.ai-project/artifacts/agentic-runs/<id>/`
   convention**, with a `P9-M31-E31.2__run-record.md` cross-linked from the policy file's
   revisit trigger — the same shape E26.3 established, chosen for consistency over
   inventing a new location.
