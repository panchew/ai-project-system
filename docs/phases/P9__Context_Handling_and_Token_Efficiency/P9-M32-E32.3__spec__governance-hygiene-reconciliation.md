## Problem Statement

Two P8 documentation debts remain live: governance prose describing this repo as opted out
of `visual_artifacts` when it has been enabled and passing a real endpoint test since
E29.2 (P8-GH-1), and six pre-P9 planning documents using a vestigial "Phase Delivery
Notice" phrase that names no artifact PSG §5C's actual closure sequence produces (P8-GH-3).
Both are HQ-triaged Into P9, both routed here. P8-GH-2 (machine-local hosting) stays
deferred on its own recorded trigger — this Epic's only obligation toward it is to confirm
it wasn't silently dropped along the way.

---

## Goals

By the end of this Epic:

1. **P8-GH-1 is reconciled** — no governance surface describes this repo as opted out of
   `visual_artifacts`; AOG §16.5 and `visual-artifacts.md` both state the current, accurate
   status.
2. **P8-GH-3 is reconciled** — no living pre-P9 planning document or template still uses
   the vestigial "Phase Delivery Notice" phrasing, except the P8 closure declaration's
   intentional carry-forward record, which is preserved verbatim.
3. **P8-GH-2's deferred status and trigger are restated**, somewhere reachable from this
   Milestone's own closure record — confirmed, not resolved, not silently dropped.

---

## Non-Goals

This Epic explicitly does **not**:

- Enable, disable, or otherwise change `visual_artifacts.enabled` or any other
  `.ai-project.yml` behavior — this Epic corrects prose to match the config's already-true
  state (`enabled: true` since E29.2), it does not touch the config itself.
- Resolve P8-GH-2 (machine-local hosting) — stays deferred on its recorded trigger; restate
  only.
- Touch P9's own planning documents' "Phase Delivery Notice" occurrences — verified clean
  (quoted discussion only), per Grounding; editing them would be a false-positive fix, not
  a real one.
- Touch E32.1's or E32.2's surfaces — fully independent (protocol, hierarchy, templates for
  the system participant vs. AOG/visual-artifacts.md/pre-P9 docs for hygiene). No shared
  files.
- Add new "Phase Delivery Notice"-purge scope beyond the six identified documents and
  templates carrying copy-paste risk — this Epic fixes the confirmed-live instances, it
  does not go hunting for a broader rewrite of historical phase documents' wording beyond
  the one phrase.
