manual instances a declared Execution Mode; E31.2 gave the agentic path a

## Design Decisions (spec §Design Decisions, resolved)

1. **Mapping = Option A** (reuse `.ai-project.yml` keys where they exist; add
   `creation` and `epic_manual` as the only two genuine gaps) — not a separate
   companion mapping. Absent-block/absent-key = documented **permissive default**
   (fresh projects, and existing `models:` blocks that predate this Epic, must still be
   able to open a chat) — the alternative ("cannot verify, therefore refuse") was
   considered and rejected as disruptive to the framework's own default init behavior.
2. **Verification method = harness self-report**, no alternative channel found or
   reasonably inferable in this environment; documented with its limit stated.
3. **Instruction location** = the existing "Prerequisite Verification" /
   "Spec Existence Requirement" sections on the three Execution Chat Starters (natural
   sibling to the git-tracked-ness check already there); a new "Prerequisite
   Verification" section added to `hq-chat-opener.md`, `genesis.md`, and `seed.md`,
   which had no equivalent section before this Epic.
4. **Divergence check = a new, self-contained check** against `chat-hierarchy.md`'s own
   table (Design Decision 4, second branch) — not an extension of
   `model-routing-policy.md`'s mapping table or `DEFAULT_MODELS`, since neither covers
   (nor should cover) keys with no agentic dispatch role. Kept in the same file
   (`tests/test_model_config.py`), same narrow-parser style as E31.2's existing guard,
   for consistency without conflating two genuinely different sources of truth.
