## Why this session did not actually stop

No guardrail existed on either starter at the moment this session opened under each role
— this Epic is the work that creates the instruction. Building it necessarily requires a
session to execute Epic-level work in the interim; halting the session that builds the
guardrail, before the guardrail exists to require it, would be incoherent. This document
is the honest record of what *would* happen, and *will* happen for any future manual
session in this condition, once this Epic's edits to the five template surfaces are
merged. It is deliberately not framed as "this session refused" — it did not, because
nothing yet told it to. It is framed as "this session's real, current facts, run through
the instruction this Epic delivers, produce a refusal" — which is the honest and
falsifiable claim this evidence deliverable requires.
