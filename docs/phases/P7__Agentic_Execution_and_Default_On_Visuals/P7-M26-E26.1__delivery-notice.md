# Epic Delivery Notice — E26.1

**Epic:** E26.1 — The `run-dev-agent` adapter (CONTRACT §7 shim)
**Status:** Execution Complete, Delivered for Review
**Delivery Date:** 2026-07-12

## Execution Summary

Built `bin/run-dev-agent`, the CONTRACT §7 adapter between the P3 orchestrator and
`local-agent-runner`, plus the coding-set `tools.json` and 26 contract tests (runner
stubbed). The adapter reads `AI_PROJECT_ACTIVE_MODEL` (mapping `local:<tag>` → bare
`<tag>`; missing/empty → exit 3 with a one-line stderr reason), reads the trigger JSON
from `.ai-project/queue/04_epic.json`, extracts the spec's Definition of Done as
`--task-text`, passes the scoped spec (+ chat starter when present) as `--context`,
invokes the runner with `--tools`/`--transcript`, and returns the runner's exit code
unaltered. No orchestrator changes; the adapter fits the existing env + mounted-repo
invocation.

The four Epic-level design decisions, resolved and documented in the adapter's module
docstring:

1. **DoD sourcing** — trigger JSON from `.ai-project/queue/04_epic.json` (CWD-relative;
   workdir = repo root in both sandbox and local-fallback paths) → `epic_spec_path` →
   the spec's "Definition of Done" markdown section (##/### heading through the next
   same-or-higher heading). Missing trigger/spec/section → exit 3, never silent.
2. **Runner discovery + reachability** — `LOCAL_AGENT_RUNNER` env override, else
   `local-agent-runner` on PATH, else exit 3. Ollama endpoint defaults to the runner's
   own default; `AI_PROJECT_OLLAMA_ENDPOINT` is forwarded as `--endpoint` for contexts
   where localhost does not reach the ollama host (sandbox). E26.3 exercises this live.
3. **Transcript convention** — `.ai-project/artifacts/agentic-runs/<epic_id>/` holding
   `transcript.json` (runner-written, passed through as produced — the adapter never
   opens it), `context.md` (the exact context handed over, so token discipline is
   auditable), and `run-metadata.json` (model, runner, exit code, timing).
4. **tools.json location** — `.ai-project/agents/tools.json` (the E25.3 agents home),
   git-tracked, CONTRACT §4 shape: the six coding tools, paths scoped to
   `/workspace/**` + `./**`, commands limited to the pytest surface, git subcommands
   allowlisted, timeout 300s.
