### Summary

Build `bin/run-dev-agent` — the CONTRACT §7 adapter shim between the P3 orchestrator and
`local-agent-runner` — plus the coding-set `tools.json` and contract tests (runner **stubbed**;
the live invocation is E26.3's job). It is the only governance-aware piece of the execution
path; the orchestrator already names it as the default `dev_command`, but the file does not
exist.

### Binding constraints (carry into every decision — verbatim from the Milestone spec)

- **No `final_answer` parsing anywhere in the adapter** (SN-3 / runner P1 audit). Epic success
  is the QA `validation_command` exit code + transcript, never prose.
- **`--context` = scoped epic spec/starter only — never full governance** (CONTRACT §6 token
  discipline: scoped ≈ 24K tok vs. full governance ≈ 157K tok — a defect, not a convenience).
- **The runner's exit code is returned unaltered** to the orchestrator (0/2/3/4 pass through).

### Adapter behavior (CONTRACT §7)

1. Read `AI_PROJECT_ACTIVE_MODEL`; map `local:<tag>` → bare `<tag>` for `--model`; bare tag
   passes through; missing/empty → config-error exit with a one-line stderr reason.
2. Locate the epic's DoD + scoped spec — recommended route: read the trigger JSON from
   `.ai-project/queue/` (the orchestrator does NOT pass trigger fields through the env; the repo
   is mounted at the working directory) and take `epic_spec_path`; `--task` = the spec's DoD,
   `--context` = the scoped spec/starter.
3. Invoke the runner: `--model`, `--task`/`--task-text`, `--context`, `--tools` (the coding-set
   `tools.json`), `--transcript` (the epic's artifact path).
4. Return the runner's exit code unaltered.
5. Write the transcript into the epic's artifacts — git-visible and stable (it is also the
   cross-repo E3.2 evidence). Recommended: `.ai-project/artifacts/agentic-runs/<epic_id>/transcript.json`.

**Epic-level design points (yours to resolve — decide, document, move; escalate only if truly
blocked):** DoD-extraction mechanics; runner-binary discovery + Ollama-endpoint reachability
(sandbox vs. documented local fallback; `--endpoint` override); exact transcript path
convention; `tools.json` location.
