## Execution Route (required disclosure)

**Local-execution fallback, not the Docker sandbox**, per the Milestone Chat's first
resolution (`362e2d5`): the sandboxed route cannot reach this host's Ollama endpoint or the
runner binary, and bare `alpine:latest` lacks `python3`. The orchestrator was invoked with a
curated `PATH` (containing only symlinks to `git` and `python3`, omitting `docker`) so its own
`subprocess.run(["docker", ...])` call in `run_in_sandbox()` raises `FileNotFoundError`,
triggering its already-implemented local-fallback branch. Exact invocation:

```bash
env -i HOME="$HOME" USER="$USER" PATH="<curated-dir>" \
    LOCAL_AGENT_RUNNER="<wrapper-script>" LANG=C.UTF-8 LC_ALL=C.UTF-8 \
    python3 bin/ai-project-orchestrator
```

`LOCAL_AGENT_RUNNER` pointed at a one-line wrapper (`local-agent-runner` is not installed as a
console script on this host — a same-repo execution-environment choice, per the second
resolution):

```sh
#!/bin/sh
PYTHONPATH="<local-agent-runner milestone/M3 worktree>" exec /usr/bin/python3 -m local_agent_runner "$@"
```

**The runner ran against `local-agent-runner`'s `milestone/M3` (commit `b5a848b`, includes
`40610f0` which adds `--context`), not the checked-out `phase/P2` — required disclosure per
the Milestone Chat's second resolution (`97637af` → resolved).** `phase/P2` predates
`--context` (`bin/run-dev-agent` requires it; `local-agent-runner`'s own `phase/P2` history
shows an HQ-ordered hold on exactly this dependency, pending this repo's adapter — now cleared
from this side, not yet mechanically consolidated on that side). The Milestone Chat authorized
pinning to `milestone/M3` via a `git worktree` (`git worktree add <dir> milestone/M3`) — a
read-only, no-write, fully reversible reference to that repository's own already-accepted ref
(`5db0094 merge(P2-M3): accept Epic E3.1`), not a change to it. This choice, and the reasoning
for it, is carried forward here verbatim for `local-agent-runner`'s own P2-M3 Milestone Chat to
see when it reviews this evidence for the cross-repo hand-back.
