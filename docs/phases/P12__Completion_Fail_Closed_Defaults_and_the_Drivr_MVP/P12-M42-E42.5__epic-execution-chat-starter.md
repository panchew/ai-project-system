## ⚠ Hard Constraint — inherited from the M42 milestone spec

> **The machinery under repair must not supervise its own repair.**

- **Execution posture: `manual` / paid frontier.** This instance is manual for exactly that reason.
- **On "prove the guard by falsifying" — stated honestly, because it applies to you differently.**
  You change no code and invert no test; **there is no guard to falsify.** Your equivalent is the
  **absence discipline**: a sweep that reports "no placeholder here" must have run a check that
  *would have found one*. **A size check does not** — a size check that reports *no other placeholders*
  is the milestone's own defect wearing your name.
- **State the layer, time and scope of every claim** (`P11-GH-2`). *"`wc -c` says 14,711"* is a
  different claim from *"the front-matter says `name: hq`"* — report which, and where.
- **Falsify a pattern before trusting a zero result.** `grep -rln 'governance.agent.md'` finds the
  file; it does not find whether the file is a stub. `find ~/soft-dev` finds directories; it does not
  find which are enrolled.
- **An absence is only evidence when the thing that would have created it actually ran.** This is the
  whole of Obligation 3's *are these paths live?* — do not answer "not live" with *"I found no caller"*
  unless you ran the inspection that would have found one.
