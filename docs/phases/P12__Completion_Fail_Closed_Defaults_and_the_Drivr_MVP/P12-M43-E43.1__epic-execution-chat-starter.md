**`P11-GH-1` is an active risk — it fired four times in P11 and repeatedly this phase.** The backstop

*arrived* on the branch and was still not applied. The procedure, and its widened backstop:

1. **Amend the governing spec file on the branch that owns it**, with a changelog row.
2. **Notify every running child chat in-session**, naming the file and section. **This step is the one
   that fires** — a write nobody is told about is not a channel.
3. **Require the child to re-read the named section before its next deliverable and to state, in that
   delivery, that it did.**
4. **If the amendment is blocking, escalate to the Phase Chat for a pause/cancel decision.**
5. **Before you accept any delivery, `git log` this spec against the branch point — AND against every
   artifact this Starter restates a rule from.** A Starter restates rules whose sources live
   elsewhere; the widened backstop covers them all, not one document.

**Your obligations, specifically:**
- **`git log <your-spec-path>` against your branch point before you deliver**, and re-read the
  milestone spec's W2/W4 findings.
- **Pin the ref in every measurement.** `git log -1 … -- '<path>' <ref>` places the ref after the
  `--`, falling back to implicit `HEAD` — a check that can return a different valid-looking answer to
  each reader (milestone spec v1.1.3). Put the ref **before** the `--`, name `origin/<branch>`, and

## Summary

**Relocate the merge from the child to the parent, so a bypass class becomes unavailable rather than
discouraged.**

*behaviourally* (a rule about how to refuse). The structural fix: **if the parent performs the merge,
the child never holds the authorization at all.** The core work is a **re-authoring** of
`governance/templates/merge-authorization.md` — its subject, fields and post-conditions are all
child-addressed (W4), so this is *not* SN-31's *"one template edit"*. E40.5's guard demotes to a
labelled **backstop**, not a deletion. The surface set is stated **itemized, never counted** (W2), and
a check proves no surface instructs a child to hold merge authorization.
