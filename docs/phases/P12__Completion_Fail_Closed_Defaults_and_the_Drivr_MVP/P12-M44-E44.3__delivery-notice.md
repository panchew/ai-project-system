## Deliverables

### D1 — The fourth state, defined alongside the existing three ✅

`chat-hierarchy.md` §Manual Chat Model Verification gains **"Config present +
self-report absent: refuse by default; the recorded-declaration exception"** (after "The
blocking behaviour…", before Handback). The state is defined, the disposition stated as
**ruled** (R6 Decision 3, not re-decided), and the four states are **itemized** — agree /
disagree (advisory default, blocking opt-in, SN-40) / config absent / config present +
self-report absent — with **no state reached having said nothing**.

### D2 — The recorded-declaration exception, E42.1 parallel stated ✅

The exception requires: a human declares the running model explicitly; the chat states in
its **first substantive response** that it proceeded on a declared rather than
self-reported identity, and what was declared. **Silence is never available.** The E42.1
parallel is stated, not left for a reader to notice.

### D3 — The text does not assume Claude Code ✅

The condition is defined by the **absence of a self-report to read**, not by which
harness is in use; the framing notes the self-report is observed only on this
repository's harness and three of five targets move off it. Claude Code is one surface
among several, never the assumed one.

### D4 — The why-of-the-exception ✅

Stated: the self-report is already conceded unverifiable ("Known limit, stated plainly");
a recorded human declaration is the **same epistemic strength with a named accountable
party**; without the exception the rule is a **wall, not a gate**.

### D5 — The inter-chat paragraph, in the normative tier ✅

**Placement decision (delegated): `chat-hierarchy.md`**, as the section **"Cannot
establish a sender's role? Refuse — the counterparty layer (`P12-GH-4`, narrow half)"**
directly below §Manual Chat Model Verification — so the self and counterparty cases read
as **one rule at two layers** in one document. It restates **SN-36** (a chat reply is
never authorization, because agents can write into chats), names **inbound as the threat
model** with the reason, lands the content-fixed paragraph **verbatim**, states the
**exception asymmetry** (self carries the exception, counterparty none), and **does not
design the channel** — the wider half is cited as filed unowned.
