**Approval failure is a warning, and the merge ladder escalates privilege in answer to refusal — and a
test records that as correct.**

falls into a ladder (`:277` standard → `:279` `--admin` → `:281` `--auto`). The `--admin` rung

asserts the override succeeds against a branch that said no.**

exercises the *ladder* — the `:269` approval-bypass path has **no test at all**. You owe a **new**
test for the approval abort alongside the inverted ladder test.
