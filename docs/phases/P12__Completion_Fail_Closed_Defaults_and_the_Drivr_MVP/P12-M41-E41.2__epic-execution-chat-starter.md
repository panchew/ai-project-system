The Epic spec is the single authoritative copy of this Epic's **Deliverables (D1–D6), Definition of
Done, Acceptance Criteria, Binding Constraints, Technical Constraints, Design Decisions Delegated,
Non-Goals and Notes.** **This starter does not duplicate them.**

**The five things easiest to get wrong, flagged here and specified there:**

1. **Validate in BOTH directions (S1).** Three positives *and* **two negatives**. **If your
   instrument flags E33.2 Run B or E33.4, it is wrong** — those runs shipped committed, green work.
   Fix it, and **record that it was wrong before it was right.** An instrument validated only on
   failures is a device that has been shown to say "no".
2. **Never score the exit code (S2).** Run A: **exit 0**, 0 rounds, nothing. Run B: **exit 2**, 10
   rounds, mergeable work committed at `4ec1e8f`. Record exit status as context; scoring it measures
   the wrong variable, and this project has measured it wrong in both directions already.
3. **An unloadable replay case fails LOUDLY (S3).** Run B has a transcript and **no run-metadata
   file**. A metadata-requiring replay skips it silently and reports four cases instead of five.
   **Declare the set first; never report a shorter list.**
4. **`epic_qa`'s floor is RULED — per-lane (S5), and the verdict is UNBLOCKED.**
   `bin/run-qa-agent:336-344` **refuses to dispatch** under a mutating tool set, so *files changed >
   0* was a floor **no honest QA run could ever clear** — a **constant false**, not a strict bar. The
   CFO ruled it per-lane on 2026-08-20: **`epic_dev` keeps `rounds > 0` AND `files changed > 0`;
   `epic_qa` takes `rounds > 0` AND `claims resolve`, with `files changed` recorded but not
   scored.** **Apply it, and STATE WHICH VERSION OF THE FLOOR YOU APPLIED** — a run judged against
   the pre-ruling floor is not comparable to one judged against the ruled floor. **⚠ Criterion 2 is
   untouched: reaching the floor by enabling a mutating QA tool set is refused in advance, and a
   floor cleared that way is not a cleared floor.**
5. **The tasks are the experiment (spec §Scope 4).** Comparable across models, **not answerable from
   this repository**, genuinely lane-shaped, and **committed with their inputs** so E41.3 runs the
   identical task rather than a paraphrase.
