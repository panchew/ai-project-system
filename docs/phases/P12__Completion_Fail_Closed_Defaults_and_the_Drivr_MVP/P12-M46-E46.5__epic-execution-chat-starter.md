**The five things easiest to get wrong, flagged here and specified there:**

1. **Committing the bar after the suite.** The bar is the *first commit* — a threshold committed
   after the candidate is seen grades the measurement it was written from (V5).
2. **`COULD_NOT_MEASURE` reading as `FAIL`.** An empty credential store is not an unreachable
   target, and neither is a `FAIL`. Three-valued, or it is not a gate (phase spec v1.2.0).
3. **The exit code as a signal.** E33.2 Run A exited 0 having done nothing. Record it; never score
   it (E41.2's S2).
4. **Re-implementing the instrument's checks silently.** If the gate's "tool round" diverges from
   the instrument's, two instruments disagree. State the relationship; do not diverge silently.
5. **Finishing on the epic branch only.** The gate, the bar, and their tests must be on Drivr
   `main` (BC9).
