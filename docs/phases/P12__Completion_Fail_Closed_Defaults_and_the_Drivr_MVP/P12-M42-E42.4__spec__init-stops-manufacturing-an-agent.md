# Epic E42.4 — `ai-project-init` Stops Manufacturing an Agent

## Context

M42 exists to close one disposition across four `bin/` paths: *when the evidence that should gate an
action is absent, the action proceeds.* E42.4 is the fourth path — the **enrollment tier** — and the
one with a **live victim**. It is `P12-GH-2`, severity **High**, and the only one of the four defects
not on `bin/ai-project-orchestrator` (E42.1/E42.2) or `bin/ai-project-git-merge` (E42.3).

`bin/ai-project-init`'s `install_hq_agent` (`:323-354`) is meant to install a real governance agent
into a newly-created project. When the real agent is missing, it **manufactures a substitute and then
validates the substitute**:

1. **`:328` reads the wrong source path.** `local src_file="$project_dir/governance/agents/governance.agent.md"`.
   But `add_governance_submodule` (`:274`, `:294`) clones the **whole** `ai-project-system` repository
   into `<project>/governance` — and inside *that* repository the agent lives at
   `governance/agents/governance.agent.md` (verified as the **only** file of that name in the tree).
   So after a real submodule install the agent is at `<project>/governance/governance/agents/governance.agent.md`
   — **one `governance/` level deeper than the path read.** The source is never found.
2. **`:336-346` writes a 230-byte stub** whose body says *"This agent is under development in Milestone
   M8."* **M8 closed in P2.** The temporary branch has been the only reachable branch for at least
   nine phases. Anchor: `This agent is under development in Milestone M8`.
3. **`:348-353` validates the stub it just wrote.** Readable (`:349`), non-empty (`:350`), first line
   matches `^(#|---)` (`:351-352`). **The stub satisfies all three** — it begins `# HQ Chat Agent`.
   The validator tests the properties a placeholder trivially has, never the property that matters:
   **that the file is the governance agent.**

**A second defect travels in the same script.** `write_project_config` writes at `:262`
`submodule_path: governance/` against the fleet's **`.governance`** convention (M38: 8 of 11 projects;
the three exceptions are exactly the projects init created). `add_governance_submodule` writes the
submodule to `governance` too (`:274`, `:294`, `:298`). **A project that follows the convention has
its governance somewhere init never looks** — which is why the first defect is universal rather than
occasional.

**This is the fail-open disposition in its purest form:** the evidence is absent, so a substitute is
manufactured, and the check is written against the substitute.

**It is also one of the two self-protecting tests.** `tests/test_init_agent_path.py` invokes the script
with `--skip-submodule` (`:24`) and asserts the file exists, is non-empty, and begins with `#` — **the
same three properties the stub satisfies.** The branch that would fail is **unreachable under its own
invocation**. It correctly guards `P6-GH-11` (the canonical `.ai-project/agents/` path — the old
`.github/agents/` path must not be written), and that coverage **must survive** the inversion.

E42.4 is sequenced **before E42.5** — a fleet sweep cannot say what "repaired" means until this fix
exists.

---

## Problem Statement

**The initializer reports success on the one outcome it must not produce, and a test records that as
correct.**

Three failings, each a layer of the one defect:

1. **The source path is off by one `governance/` level**, so the real agent is never found after a
   real install — the failure is **universal**, not occasional, because a convention-following project
   keeps its governance where init never looks.
2. **The un-found agent becomes a manufactured placeholder**, dating from Milestone M8 (closed in P2),
   which has been the only reachable branch for nine phases.
3. **The validator checks the placeholder's properties, not the agent's.** Readable, non-empty,
   starts-with-`#` — all trivially true of a stub. The property that matters — *is this the governance
   agent* — is never tested.

**Why this is severity High** (the `P12-GH-2` note's own words): it fires silently on every install
(no warning a human would notice — the script reports success); it has a **live victim already**
(`social-stories-creator`, 230 bytes); and it is the **enrollment tier**, so the wrong agent is
inherited by every project the framework onboards — including the first external adopter.

**Why it lands here on its own merits, not as a reconciler component.** The governance-auto-update
reconciler is split and out of P12 entirely. `ai-project-init` is repaired **as a fail-open defect**.

---

## Goals

By the end of this Epic, the system must:

1. **Correct the source path at `:328`** so it resolves after a **real** submodule install, consistent
   with whatever submodule path the script actually writes (see goal 4).
2. **Remove the stub-writing branch.** Not improved, not made louder — **removed.** Absent source →
   the script fails with a stated reason. **Manufacturing a substitute is the one answer that must not
   survive this milestone.**
3. **Strengthen the validator** to test the property that matters — that the file is the governance
   agent — not the properties a placeholder trivially satisfies.
4. **Write `submodule_path` to match the fleet convention (`.governance`)**, and dispose of the M38
   hard-coding finding deliberately (a flag, or a documented deliberate hard-code).
5. **Invert `tests/test_init_agent_path.py`** so a placeholder is not installable at all, **with
   `P6-GH-11`'s canonical-path coverage preserved.**
6. **Run a real end-to-end `ai-project-init`** (Obligation 1), no `--skip-submodule`, and capture —
   **honestly** — whether the result confirms or falsifies the inferred mechanism.

- **Build the governance-auto-update reconciler.** That work is split; neither half is in P12. This

- **Change the agent's content or location in this repository.** `governance/agents/governance.agent.md`

- **Fix the sandbox, staging, or merge paths** — E42.1/E42.2/E42.3.
- **Touch Drivr.**

## Scope of Work

### 1. The source path, corrected (D1)

Fix `:328` so `src_file` resolves to where the submodule actually puts the agent. **This fix and the
submodule-path fix (D4) are coupled and must be made consistent in one change**: if the submodule lands
at `governance`, the source is `$project_dir/governance/governance/agents/governance.agent.md`; if at
`.governance`, it is `$project_dir/.governance/governance/agents/governance.agent.md`. The epic states
the resolved path and proves it against the real submodule layout — not by re-reading a number.

### 2. The stub branch, removed (D2)

Delete `:333-346`'s `else` branch. Absent source → the script **fails with a stated reason** (the
script's own `error` helper is the existing convention). No placeholder, no fallback, no
"under development". The comment naming M8 goes with it.

### 3. The validator, strengthened (D3)

Replace the `:348-353` checks so they assert the property that matters. **This is the delegated design
decision** (see below) — provenance, a known marker, or a checksum. The real agent has front-matter
`name: hq` / `version: 2.1.0` (14,711 bytes), which is a natural marker; E36.3's `sha256` freeze is
available precedent and is **not** mandated. Whatever is chosen: **the stub must fail it**, and the
reasoning must state why the check cannot be satisfied by a substitute.

### 4. `submodule_path` → `.governance`, hard-coding disposed deliberately (D4)

Change `:262` (and the `add_governance_submodule` clone path at `:274`/`:294`/`:298`) from `governance`
to `.governance`, matching the M38 fleet convention. **And dispose of the M38 escalation's finding**
— *"init hard-codes the path with no flag"* — deliberately: either add a flag, or record that it
remains a hard-coded default with its reason. Leaving it hard-coded **and silent** is not an option.

### 5. The test, inverted with `P6-GH-11` preserved (D5)

Invert `tests/test_init_agent_path.py` so a **placeholder is not installable at all**, while preserving
the canonical-path coverage (`P6-GH-11`): the file is written to `.ai-project/agents/governance.agent.md`,
never `.github/agents/`. The current test's `--skip-submodule` invocation can only reach the stub
branch; the inverted test must exercise the **real** path (or assert that the stub branch is
unreachable). **The epic decides the test shape**, with one binding requirement: the suite must fail
if a placeholder agent is installable, and must still fail if the `.github/agents/` path regresses.

### 6. Obligation 1 — the real end-to-end run (D6)

Run **`ai-project-init` end-to-end, without `--skip-submodule`**, into a scratch directory, and capture
what it does. **This is a run, not a read** — the `P12-GH-2` note states its own verification boundary:
paths read, live victim taken from the record, **no end-to-end init run**. M42 runs it.

- **If it confirms** the stub is produced (on the un-fixed script), the diagnosis is confirmed; the fix
  is then demonstrated to produce the real agent instead.
- **If it falsifies** — the run does **not** in fact produce the stub — **say so plainly**, and record
  the finding as shrinking to the validator and the test, which are defects on their own terms and are
  fixed regardless. **Do not quietly drop the correction** — a diagnosis that survives its own test is
  worth more than one never tested.

The result — confirming or falsifying — is **stated**, with the layer, time and scope of the run.

## Binding Constraints

Settled above this epic — **not re-decidable here**:

1. **E42.4 is sequenced before E42.5.** A sweep cannot say what "repaired" means until this fix
   exists.
2. **M42 gates M47.** No M47 epic may be dispatched agentically until this milestone closes.
3. **The tests are inverted, not deleted.**
4. **`ai-project-init` is repaired on its own merits** as a fail-open defect. **It is not a
   governance-auto-update reconciler component** — that work is split and neither half is in P12.
5. **A surviving permissive path must be declared AND recorded.** If any path remains where an absent
   agent is not an error, it must be an explicit, recorded, declared decision — not a silent fallback.
6. **Obligation 1 is run, not inferred.** The `P12-GH-2` note's own boundary says no end-to-end run was
   done. If the run falsifies the inference, say so — do not shrink the scope quietly.

## Hard Constraint (binding — carried to every Epic)

- **Execution posture: `manual` / paid frontier.** This epic modifies the initializer. **The machinery
  under repair must not supervise its own repair.**
- **Prove the guard by falsifying it.** The strengthened validator and the inverted test each **fail**
  when the guard is removed — you owe it for both.
- **Cite by anchor, not by a bare line number.** `bin/ai-project-init` and the test were unaffected by
  the orchestrator's +4 drift, but the rule holds: search for `local src_file=`,
  `This agent is under development in Milestone M8`, `submodule_path:`, `--skip-submodule`.
- **`--include='*.py'` skips every `bin/` entry point** — and `bin/ai-project-init` is an
  **extensionless** script, so a `*.py` name-sweep finds nothing.
- **An absence is only evidence when the thing that would have created it actually ran** — which is the
  whole reason Obligation 1 exists.

   front-matter is a natural marker.
2. **How `submodule_path` hard-coding is disposed of** — a flag, or a documented deliberate hard-coded
   default, with the reasoning stated.

   unreachable) while preserving `P6-GH-11`.

The milestone starter names the first explicitly as this level's decision; the second follows the M38
escalation's *"dispose of that deliberately"*.

## Execution Notes

**Order:**
1. Confirm the defect anchors **by search, not by number**, and re-inspect the real agent's content
   (`name: hq`, `version: 2.1.0`, 14,711 bytes) — it is what the validator will key on.
2. Fix the source path (D1) and the submodule path (D4) **together** — they must be consistent.
3. Remove the stub branch (D2); strengthen the validator (D3).
4. Invert the test, preserving `P6-GH-11` (D5).
5. Falsify both guards — delete the validator assertion and watch the test fail; delete the
   no-stub-abort and watch the test fail.
6. **Run the end-to-end init (D6)** into a scratch dir; report confirming-or-falsifying honestly.
7. Run the suite; state the invocation and the delta.

**Traps:**
- **Fixing `:328` without touching `:262`/`:274`** — the source path and the submodule path are one
  coupled decision; fixing one while the other stays at `governance` re-breaks the install.
- **Making the stub "louder" or "more clearly a stub" instead of removing it** — the milestone rules
  this out; the one answer that must not survive is manufacturing a substitute.
- **A validator that a substitute can still trivially satisfy** (e.g. any file starting with `#`).
- **Falsifying the inference and then quietly dropping the correction** — a run that says the stub is
  not produced shrinks the finding to the validator and the test, and that must be stated, not buried.
- **Citing the +4 drift on this file** — `bin/ai-project-init` was not shifted; but re-verify by anchor
  regardless.

## Notes

- **The live victim makes this different from the other three.** `social-stories-creator` still
  carried a 230-byte placeholder (confirmed by the Phase Chat's G4 re-inspection, 2026-08-19) — the
  defect has already fired, before any agentic operation. Repairing that install is **not this epic's**
  (E42.5 enumerates the fleet); this epic removes the *machinery* that manufactures more victims.

- **On Obligation 1, and the honesty it demands.** The `P12-GH-2` note's verification boundary is
  explicit: *paths read, victim taken from the record, no end-to-end init run.* The inference — *a real
  init today produces the stub* — follows from two verified paths but was **never executed**. This
  epic executes it. If the run falsifies the inference, the correction **shrinks, not silently drops**:
  the validator and the test are still defects and still fixed. A diagnosis tested by its own run is
  worth more than one that is not.

- **On why the two path fixes are one decision.** `:328` (agent source) and `:262`/`:274` (submodule
  path) describe the same location twice. Fixing one while the other stays at `governance` leaves a
  project whose agent lives where init never looks — which is the *cause* of the off-by-one being
  universal rather than occasional.
