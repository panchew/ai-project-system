once in each direction.** P12 runs three parallel tracks. **Assume it will fire again.**

1. **The spec file is amended on the branch that owns it**, with a changelog row.
2. **You are notified in-session, naming the file and the section that changed.** **This is the step
   that fires** — a write nobody is told about is not a channel.
3. **You re-read the named section before your next deliverable and state, in that delivery, that you

4. **If the amendment is blocking, it escalates** rather than letting you finish invalidated work.
