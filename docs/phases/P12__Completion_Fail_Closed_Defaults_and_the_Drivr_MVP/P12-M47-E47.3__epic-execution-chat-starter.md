**The five things easiest to get wrong, flagged here and specified there:**

1. **The run's own report as evidence.** E39.3 printed `VERDICT: PASS` with zero rounds and a key
   the file did not contain. The instrument is the checker, not the run.
2. **An exit status standing in for the counts.** E33.2 Run A exited 0 having done nothing. Tool
   rounds, files changed, claims-resolution — never an exit status.
3. **Interpreting `undetermined` instead of recording it.** The completion verdict is recorded
   *as given*; a human-substituted judgment is a separate, labelled claim.
4. **Overclaiming from one run.** One project, one epic, one engine proves exactly that — no more.
5. **Blurring the proof's subject into its supervision.** The run is the subject (agentic); the
   supervision (this chat) is manual. Keep them distinct in the record.
