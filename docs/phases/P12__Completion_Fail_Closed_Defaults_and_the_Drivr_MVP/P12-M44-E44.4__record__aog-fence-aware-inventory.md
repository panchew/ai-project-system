## The inventory — the AOG's `## ` headings, fence-aware

**The pattern used to make the fence distinction (stated, per the Hard
Constraint).** A line is a **real fence delimiter** when, with 0–3 leading
spaces, it is a run of three or more backticks followed by at most an
info-string (which, per CommonMark, cannot contain a backtick) and trailing
whitespace before end-of-line:

```
^ {0,3}(`{3,})(?:[^\n`]*)?\s*$
```

That rule rejects the AOG's `:134` line —

```
   ````markdown name=<artifact-filename>.md`` `
```

— for **two** independent reasons: it is indented inside a numbered list item
and, decisively, it carries a trailing stray backtick run after its info string,
so it is a *prose illustration* of the four-backtick fallback form, not a real
delimiter. The **parity self-test** is carried on the real-fence count: 16
(even). A toggle detector that treated any backtick run as a fence would count
17 (odd) and desync at `:134`, inverting its classification for the remaining
~900 lines — this detector would fail loudly on an odd count instead.

## The fence detector's hazard is live, not hypothetical

The naive toggle detector (treat every backtick run as a fence) counts 17 fence
lines — **odd** — and classifies `## 4. Authority Hierarchy` through
`## 11. Human Review and Epic Review Seal` as *fenced*, yielding 13 real / 16
fenced with zero "Error Handling" titles. That is the Phase Chat's wrong run,
reproduced. The correct detector (the rule stated above) counts **16** real
fence lines and classifies every one of those headings **real**, matching X1.
**The parity check is the cheap self-test that makes "about to lie" detectable**,
and the check (D5) carries it.
