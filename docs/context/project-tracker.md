# Project Tracker

This project uses **GitHub Projects** as a lightweight planning and visibility tool.

## Role of the Tracker
- Scheduling
- Visibility
- Status overview

## Authority
- Documentation in `docs/` is the source of truth
- Phase / Milestone / Epic definitions live in Markdown
- Tracker state does not override documented status

## Integration
This tracker is a projection of the canonical Phase–Milestone–Epic structure.
