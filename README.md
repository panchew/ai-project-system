# AI Project System

A formal, governed documentation system for AI-assisted project execution.

## Purpose

This repository contains the **canonical project system** used to structure, document, and execute software projects with AI assistance.

It defines:
- **Authoritative governance documents** for project structure and AI usage
- **Phased execution model** for predictable, scalable delivery
- **Documentation-first workflow** where specs drive implementation
- **Explicit context management** for AI effectiveness

This is **not an application**. It is a **system for managing projects**.

## Why This Exists

AI tools like ChatGPT and GitHub Copilot are powerful, but:
- Chats are ephemeral
- Context is fragile
- Execution scope creeps
- Decisions get lost

This system solves those problems through **structure and discipline**.
