## Known Limitations

1. **In-memory storage only**
   - Tasks are lost when program exits
   - Documented in README.md
   - Will be addressed in Milestone M3 (Data Persistence)

2. **Short ID display**

   - Full UUID used internally
   - Trade-off: readability vs. collision risk (acceptable for example)

## Lessons Learned

1. **Validation before instantiation**
   - Validating input before creating `Task` objects prevented invalid state
   - Pattern works well; will reuse in E1.2 and E1.3

2. **Type hints improve clarity**
   - Using dataclasses with type hints made code self-documenting
   - mypy caught several bugs during development

3. **Test-driven development**
   - Writing tests first clarified expected behavior
   - Achieved high coverage naturally
