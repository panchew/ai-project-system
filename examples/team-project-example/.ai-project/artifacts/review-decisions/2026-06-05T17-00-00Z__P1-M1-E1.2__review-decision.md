## Feedback

The implementation is functionally correct — all five endpoints work as specified, ownership enforcement is solid, and soft-delete behavior is correct. However, this submission is rejected for the following reason:

**1. Test Coverage Below Required Threshold**

The Completion Notice itself acknowledges coverage at 68%, below the 80% minimum specified in the E1.2 Definition of Done. The Epic spec is explicit: coverage must be ≥ 80%.

Missing tests (as noted in the Completion Notice):
- `PUT /tasks/{id}` with invalid priority value (should return 422)
- `GET /tasks` with `page` beyond the last page (should return empty list, not 404)
- `GET /tasks` with invalid `sort_by` value (should return 400)
- `DELETE /tasks/{id}` on an already-archived task (should be idempotent)

## Authorization

Rework required. Address the following before resubmitting:

1. Add the missing test cases listed above
2. Confirm coverage ≥ 80% via `pytest --cov=src/tasks`
3. Resubmit a new Completion Notice (v1.1) when ready

**Note:** The underlying implementation does not need to change — only the test suite needs to be extended. This should be a 1-day rework.
